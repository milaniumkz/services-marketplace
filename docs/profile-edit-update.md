# S11.edit: редактирование профиля

19 октября 2026 редактор приведён к структуре исходного S11.edit: фото по центру с подписью «Изменить фото», имя, выбор города, выбор языков общения, собственный номер с пояснением приватности и нижнее сохранение. Демонстрационные имя/номер не копируются в приложение; используются данные собственного GET /me. Макетная кнопка сохраняет настоящие значения вместо демонстрационного перехода.

Город выбирается из реального /geo/cities текущего регионального API: есть загрузка, ошибка с повтором, поиск, подтверждение и отмена. Языки выбираются из поддерживаемых API значений по понятным названиям. Нельзя подтвердить пустой набор. Ввод кодов через запятую пользователю больше не требуется; отмена сохраняет прежний выбор. Пока открыт выбор, повторное действие блокируется без бесконечно работающего индикатора под диалогом.

Карточки роли удалены только из редактирования: они остаются при первоначальной настройке и на отдельном экране ролей. При редактировании PATCH не отправляет roles/active_role, поэтому не перезаписывает параллельное изменение роли старым значением. Подтверждённые ответы аватара и сохранения объединяются с собственной записью редактора: приватный номер не теряется, когда API возвращает только публичные поля. Сохранение использует последнюю версию после аватара; ошибки/конфликт сохраняют черновик. Добавлена проверка disposed API.
