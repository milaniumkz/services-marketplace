# S36.limit: полный вход после исчерпания PIN

Дата: 2026-10-19. Доработан отдельный экран и его переходы; визуальная приёмка остаётся pending.

До исправления четыре регрессионных сценария воспроизводили неверный маршрут: Back при пустой истории открывал welcome, системный Back не переводил ко входу, кнопка входа оставляла pin-limit в истории, возврат из помощи снова показывал лимит. Теперь оба вида Back и кнопка входа открывают login с очищенной историей. Помощь открывает recovery с единственным возвратом к login; цикл через pin-limit удалён. Остальные страницы сохраняют существующее правило Back.

Вынесен отдельный PinLimit вместо общего JobaStatePanel. По исходным S36.limit PNG/HTML сохранены иконка 94×94, отступы 43/58px, заголовок 25px, описание и основная кнопка. Помощь — текстовая синяя кнопка без рамки с интервалом 24px, как в макете. Нативный нижний отступ белый; приложение не рисует фиктивные часы или home indicator. Ширина и увеличение текста не запрещены: содержимое прокручивается.

Новый pin_limit_test включает весь локальный путь с настоящими LocalLock.configure/unlock и PBKDF2: первые четыре неверных PIN возвращают PIN_INVALID и увеличивают счётчик, пятый удаляет локальную запись и приводит к pin-limit. Проверены authenticated=false, localProtected=false, отсутствие записи PIN и очищенное значение vault сохранённой сессии. Во всём этом сценарии HTTP-запросов 0. Системные каналы аппаратной защиты и secure storage изолированы тестовыми обработчиками; это не проверка реального устройства. Стирание локальной сессии не объявляется отзывом серверной семьи токенов.

Проверены все три контрола S36.limit: Back, полный вход и помощь; дополнительно системный Back и отсутствие циклов истории. Отдельно проверены нативный viewport 390×844 и узкий 320×640 с text scale 1.6, включая достижимость и действие помощи.

Проверки итерации: 40 passed в pin_limit_test, unlock_flow_test, local_lock_test и widget_test; после усиления утверждения об очистке записанного vault повторно прошли 6 тестов pin_limit_test. Анализатор — 0 issues. Визуальная инвентаризация — 115/115 мобильных кадров, 0 ошибок. Изменился только S36.limit-pin-limit.png.

Сравнение конкретного нативного снимка 780×1688 с оригиналом по области y=86…1643, исключающей системные полосы: MAE RGB ≈1.42411/255, different_pixels_ratio (хотя бы один канал отличается более чем на 16) ≈0.011798. Это диагностические числа, не автоматическая приёмка 1:1. Остались небольшие различия растеризации; все визуальные статусы остаются pending.
