# Админка: автоматическое открытие данных

Общий механизм заполняет служебный контекст для журнала автоматически и убирает поля `reason` и дополнительные флажки подтверждения во всех рабочих разделах, включая динамически открываемые формы. Технические права ролей, версии записей и независимое утверждение опубликованных конфигураций сохраняются; кнопки решения сами являются командой сотрудника.

При открытии пользователя номер загружается автоматически. В той же карточке параллельно загружаются последние заказы, обращения, решения, действия, услуги, портфолио, документы и селфи. Из длинных списков доступны полные разделы. Запрашиваются только блоки, разрешённые ролью; ошибки отдельного блока не закрывают остальную карточку. Фотографии загружаются через приватные ссылки, а не публичные адреса файлов.

В проверках документов и портфолио изображения открываются автоматически. В карточках заказов добавлены адрес, бюджет, согласованная сумма, сроки, результат, сведения заказчика и фотографии. Просмотры фиксируются автоматически.

История пользователя сортируется по времени, поддерживает страницы, показывает понятные названия событий на русском. Полные IP включаются только при соответствующем праве. IP не является точным адресом человека.

С этого обновления пользовательское приложение записывает переходы на экраны, сервер — успешно выполненные команды. Не записываются значения полей, PIN, пароли, текст переписки или платёжные данные. Повтор одной команды не дублирует событие. Это дополняет существующие события входа: ранее не записанные нажатия восстановить нельзя. Нативные переходы войдут в следующую разрешённую сборку APK; APK сейчас не собирается.
