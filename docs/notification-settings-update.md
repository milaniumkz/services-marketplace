# S35.notifications: настройки уведомлений

19 октября 2026 общая форма заменена отдельным экраном: заголовок «Только важное», пояснение, четыре строки с переключателями и нижняя кнопка «Сохранить». Размеры переключателей — 39×24, область нажатия — вся строка; доступны клавиатура и семантика включённого состояния. Данные загружаются из API. Демонстрационное сохранение заменено настоящим PATCH.

Сообщения, заказы, поддержка и новости имеют отдельные значения. API сохраняет `orders`/`support`, при отсутствии старых значений наследует `service`; старый клиент не стирает уже выбранные отдельные значения. Доставка проверяет соответствующую категорию перед отправкой. Отключение push не удаляет историю внутри приложения. Реклама по умолчанию выключена; существующие проверки согласия и ограничений рекламных кампаний сохранены.

Дополнение к исходному макету: сворачиваемый раздел часов тишины сохраняет ранее доступные начало, окончание, IANA-пояс и настройку прочих сервисных событий. Это требует отдельного визуального согласования. Кнопка не допускает повторного нажатия во время запроса. Ошибка сохраняет выбор; конфликт версии предлагает явно обновить настройки. Поздний ответ после смены аккаунта не вызывает переход или сообщение об успехе.

Проверено:

- 19 мобильных тестов настроек и связанных уведомлений: четыре переключателя, сохранение исходной версии и часов тишины, запрет повторной отправки, ошибка/повтор, валидация времени, смена аккаунта, ширина 320 и шрифт 200%, маршруты S31.
- 9 API-тестов настроек, кампаний и первоначальной публикации документов: сохранение/повторное чтение, старые значения, конфликт версии, неверные категории/время/пояс, независимое подавление доставки, сохранение уведомления внутри приложения.
- Реальный HTTP-прогон Flutter → локальный API: 1 passed, включая PATCH и повторный GET отдельных категорий. Анализатор мобильного кода: 0 замечаний; API TypeScript build прошёл.
- Визуальный инвентарь: 115 кадров, 0 ошибок захвата. Изменился только S35.notifications; снимок обновлён. Диагностическая доля отличающихся пикселей области приложения — 0.026680, MAE — 3.109537/255; это не процент готовности. Основная геометрия сверена с исходным PNG; всеобщая приёмка 1:1 не объявляется.

Пять исходных контролов (четыре переключателя и сохранение) получили ограниченные свидетельства поведения. Проверка исходной кнопки «Назад», отдельные сценарии ошибки загрузки/конфликта версии, все локали, часовые пояса и многоклиентская приёмка остаются в очереди. Реальная Firebase-доставка и системные разрешения устройств не проверены: провайдер не подключён.
