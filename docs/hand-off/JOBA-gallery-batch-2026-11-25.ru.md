# Несколько фотографий в галерее профиля

В «Мои услуги → Галерея профиля → Добавить фотографии → Выбрать из галереи» можно выбрать несколько JPG/PNG одним действием. Общий лимит — 20 снимков, включая уже сохранённые. Камера по-прежнему снимает один кадр.

Загрузка идёт последовательно с общим прогрессом, без одновременного запуска двадцати сетевых операций. На Android/iOS системный выбор сохраняет защиту от ложного PIN-lock при возврате из галереи; используются прежние сжатие и ограничение 2048×2048. Доступ к метаданным не запрашивается.

Перед прикреплением считывается свежая версия профиля: уже опубликованные фото и новые изменения профиля сохраняются. При сетевом сбое выбранные фото и загруженные ID остаются на открытом экране; «Повторить загрузку» продолжает с прерванного места. Повторное прикрепление одних ID не создаёт дубликатов.

Проверки 25.11.2026: 14 Flutter-тестов, 5 тестов реального браузерного input в Chrome. Проверены пакетная загрузка, сбои отправки и сохранения, повтор без повторного выбора/загрузки готовых фото, актуальные данные профиля, отмена, лимит, системный multi-picker и существующие одиночные сценарии.

Изменение требует новой нативной сборки для установленного приложения. APK по текущему указанию не собирается. Веб-версия получает изменение с серверным выпуском. Банковские интеграции и платёжные переключатели не изменяются.
