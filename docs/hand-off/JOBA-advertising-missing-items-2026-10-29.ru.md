# JOBA: что дослать из AdMob и РСЯ

Сверка по трём предоставленным скриншотам и репозиторию: 29 октября 2026 года. Инструкцию можно переслать владельцу рекламных кабинетов. Пароли, коды входа и банковские документы пересылать не нужно. Публичные рекламные идентификаторы и строки ads.txt/app-ads.txt можно прислать текстом.

## Что уже есть

| Данные | Что подтверждено |
| --- | --- |
| AdMob | Создано Android-приложение JOBA; показаны App ID и отдельный ID баннерного рекламного блока. |
| Баннер AdMob | Формат «Баннер» подтверждён вторым скриншотом. Цифры из уменьшенного изображения не переписываются, чтобы не ошибиться: нужны копии строк. |
| РСЯ | Открыта карточка приложения №20254161. |
| Баннер РСЯ | ID `R-M-20254161-1`, статус блока «Активно». |
| Приложение РСЯ | На скриншоте прямо указано: приложение в тестовом статусе, для активации нужна ссылка на приложение. |

Блоки Rewarded, веб-площадки/веб-блоки, подтверждение app-ads.txt и готовность платёжных профилей на скриншотах не показаны. Это не означает, что их точно нет в кабинетах; их данные или статусы пока не переданы.

Android package name проекта: `kz.joba.services_marketplace`. Домен веб-версии: `https://joba.com.kz`.

## 1. Google AdMob — скопировать уже созданные ID

1. Откройте https://admob.google.com/ под тем же аккаунтом, где создана JOBA.
2. Слева выберите **«Приложения» → «Все приложения»**.
3. Найдите строку JOBA, платформа Android. В столбце **«Идентификатор приложения»** нажмите значок копирования.
4. Пришлите строку целиком, вида `ca-app-pub-…~…`. Тильда `~` отличает App ID от ID рекламного блока.
5. Нажмите название JOBA → **«Рекламные блоки»**.
6. У уже созданного блока формата **«Баннер»** нажмите копирование ID. Пришлите строку целиком, вида `ca-app-pub-…/…`. Здесь разделитель — `/`.
7. Создавать второй одинаковый баннер для этого не нужно. Кнопки копирования также есть справа от строк на первом присланном экране.

## 2. Если нужен просмотр рекламы с вознаграждением — отдельный блок Google

Этот пункт нужен для rewarded-функции. Для обычных баннеров отдельное видео не требуется.

1. В AdMob откройте **«Приложения» → JOBA → «Рекламные блоки» → «Добавить рекламный блок»**.
2. Выберите **«С вознаграждением» / Rewarded**.
3. Назовите, например, `JOBA_Android_Rewarded`.
4. Не подменяйте формат обычным межстраничным объявлением или баннером.
5. Если форма просит название и размер награды, сначала согласуйте их с разработчиком. Награда должна совпадать с правилом сервера JOBA; не обещайте произвольную подписку или денежную выплату.
6. Нажмите **«Создать»**. Скопируйте отдельный ID `ca-app-pub-…/…`, подпишите «Google Rewarded Android».
7. Для серверной проверки награды разработчик должен подготовить окончательный HTTPS SSV URL. Только после этого в настройках блока заполните **Server-side verification / «Серверная проверка»** предоставленным URL. Сейчас случайный адрес или `/health` туда вводить не нужно.

## 3. Google — app-ads.txt и статус готовности

1. Откройте **«Приложения» → «Все приложения» → вкладка app-ads.txt**. Если кабинет показывает предупреждение о проверке в самой карточке JOBA, откройте его.
2. Нажмите **«Как настроить app-ads.txt» / «Настроить»**, если такой пункт показан.
3. Скопируйте точную строку Google, предложенную кабинетом, целиком. Передайте её разработчику текстом.
4. Передайте статус проверки приложения и app-ads.txt: например, ожидает проверки, подтверждено или сообщение об ошибке. Нужен текст/скрин именно статуса, а не только рекламного блока.
5. Если запрошена ссылка магазина, свяжите реальную опубликованную карточку JOBA из поддерживаемого сетью магазина. Проверьте package name `kz.joba.services_marketplace`.
6. Если приложения в магазине ещё нет, сначала нужна его публикация. Сайт joba.com.kz и ссылка на скачивание тестового APK не заменяют карточку магазина.
7. Для обнаружения app-ads.txt сайт разработчика в карточке магазина должен указывать на согласованный домен JOBA. Если это joba.com.kz, файл будет размещён по адресу `https://joba.com.kz/app-ads.txt`.
8. **Размещение файла выполняет разработчик**, а не владелец через случайный раздел кабинета. После публикации файла выполните предложенную в AdMob повторную проверку и дождитесь результата.

На момент проверки `/app-ads.txt` на joba.com.kz возвращает HTML приложения, а не файл продавцов. Это проверенный технический пробел; после получения точных строк необходимо опубликовать настоящий текстовый файл.

## 4. Яндекс — вывести приложение из тестового статуса

1. Откройте https://partner.yandex.ru/ под владельцем площадки.
2. Слева выберите **«Реклама в приложениях»**, откройте JOBA — ту же карточку, что на скриншоте, №20254161.
3. Над списком блоков, под сообщением **«Приложение в тестовом статусе. Для активации добавьте ссылку на приложение»**, нажмите **«Добавить ссылку»**.
4. Вставьте ссылку на реальную опубликованную карточку JOBA в магазине, который поддерживает форма РСЯ. Проверьте название, Android и package name `kz.joba.services_marketplace`.
5. Сохраните/отправьте на проверку и передайте итоговый статус или точное сообщение кабинета.
6. Если опубликованной карточки магазина ещё нет, не вводите вместо неё сайт JOBA, Firebase-ссылку или чужое приложение. Сначала нужна публикация JOBA; тестовое подключение SDK можно готовить отдельно.

Статус «Активно» у баннера не отменяет показанное предупреждение о тестовом статусе самого приложения.

## 5. Яндекс — блоки и строки app-ads.txt

1. В открытой карточке JOBA скопируйте ID баннера текстом. На скриншоте указан `R-M-20254161-1`; подтвердите, что это текущий нужный блок.
2. Если предусмотрена реклама с вознаграждением, нажмите жёлтую кнопку **«Добавить блок»** вверху той же страницы.
3. Выберите формат **«С вознаграждением» / Rewarded**, задайте имя `JOBA_Android_Rewarded`, сохраните.
4. Пришлите новый полный `R-M-…` ID отдельно от баннера.
5. В настройках площадки/подсказке по app-ads.txt найдите предоставленные Яндексом строки продавцов и скопируйте целиком. Если этот раздел для площадки не находится, отправьте в поддержку вопрос: «Где взять строки app-ads.txt для приложения JOBA, ID 20254161?»
6. Строки обеих сетей разработчик соберёт в **одном** app-ads.txt; не нужно заменять Google строкой Яндекса.
7. Если rewarded-награда должна открывать возможности JOBA, спросите у поддержки: «Доступно ли для приложения ID 20254161 серверное подтверждение rewarded-награды с проверкой подлинности, идентификатора транзакции и пользовательской сессии? Пришлите документацию и условия подключения». Передайте ответ разработчику. Клиентский callback SDK сам по себе не подтверждает право на награду сервером.

## 6. Если реклама должна работать в браузере

Имеющиеся Android-блоки AdMob и РСЯ не используются как веб-блоки. Для веб-версии нужны отдельные площадки и код.

**Яндекс:**

1. Слева выберите **«Реклама на сайтах»**.
2. Добавьте сайт `https://joba.com.kz`.
3. Выполните предложенное подтверждение/модерацию.
4. Создайте рекламный блок для сайта.
5. Пришлите его полный ID, код вставки и предложенные строки **ads.txt**. Это отдельные данные от мобильного `R-M-20254161-1`.

**Google:**

1. Откройте https://www.google.com/adsense/ под аккаунтом издателя, связанным с AdMob; не создавайте дублирующий аккаунт, если издатель уже зарегистрирован.
2. Перейдите в **«Сайты» → «Новый сайт» / «Добавить сайт»**, укажите `joba.com.kz`.
3. Скопируйте предложенный код подтверждения/подключения и передайте разработчику для установки.
4. После установки выполните проверку сайта, отправьте его на рассмотрение.
5. В **«Объявления» → «По рекламным блокам»** создайте нужный веб-блок и пришлите код/ID, если это доступно на текущем этапе кабинета.
6. Передайте точные строки **ads.txt** и статус одобрения сайта.

На момент проверки `/ads.txt` на joba.com.kz также возвращает HTML приложения. Файл для веб-рекламы нужно опубликовать отдельно от мобильного app-ads.txt, когда будут получены строки кабинетов.

## 7. Что дополнительно проверить владельцу кабинетов

- **AdMob:** в разделах «Платежи» и «Центр правил» проверьте запросы подтверждения и ограничения аккаунта/приложения. Передайте только статус и текст ошибки, без банковских документов.
- **РСЯ:** в «Документы» и «Настройки» проверьте заполнение анкеты, договор и данные получателя выплат. Передайте статус и незавершённые запросы, а не приватные документы в общий чат.
- Наличие созданного блока не доказывает, что анкета, выплаты и проверка приложения уже завершены. По предоставленным скриншотам это определить нельзя.
- Для получения дохода от показа рекламы не требуется пополнять рекламную кампанию Google Ads или Яндекс Директа: это отдельные кабинеты покупки трафика.

## 9. Что остаётся разработчику

В текущем проекте нет интегрированных Google Mobile Ads / Yandex Mobile Ads SDK и готовых адаптеров этих рекламных сетей. Есть общий серверный контракт провайдера, который не заменяет SDK и проверку подписанных наград.

После получения данных необходимо подключить SDK и веб-код, согласия, тестовые показы, файлы продавцов, серверную проверку наград при необходимости и проверить работу на устройствах. Ввод ID и создание баннеров сами по себе не включают рекламу. В этой сверке APK не собирался, рекламные кабинеты не изменялись и реальные показы не запускались.

Официальные инструкции, проверенные при сверке:

- ID приложения и блока AdMob: https://support.google.com/admob/answer/7356431?hl=ru
- Rewarded AdMob: https://support.google.com/admob/answer/7311747?hl=ru
- Проверка приложения через app-ads.txt: https://support.google.com/admob/answer/14538460?hl=ru
- Подключение Yandex Mobile Ads: https://ads.yandex.com/helpcenter/ru/dev/android/quick-start
