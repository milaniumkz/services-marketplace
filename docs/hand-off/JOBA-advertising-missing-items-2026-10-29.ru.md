# JOBA: актуальный список данных для рекламных сетей

Обновлено 29 октября 2026 года. Полные публичные ID: [advertising-received.json](advertising-received.json). Пароли и коды входа передавать не нужно.

## Получено — повторно не запрашивать

- Google AdMob Android App ID, баннер, блок с вознаграждением, строка app-ads.txt.
- Google AdSense: строка ads.txt и ручной адаптивный веб-баннер `8113418919`. По уточнению владельца, сайт пока на проверке.
- Яндекс Android: приложение `20254161`, баннер `R-M-20254161-1`.
- Яндекс Web: площадка `20302217`, блок `R-A-20302217-1`, загрузчик. Сайт отклонён «по иным причинам».
- Оба Google seller-файла опубликованы по HTTPS: `/ads.txt`, `/app-ads.txt`.

## Чего ещё не хватает

1. Решения AdSense по самому сайту. Пока идёт проверка, повторная заявка не нужна, реальные показы не включены.
2. Строк продавцов Яндекса из кабинета для соответствующего ads.txt/app-ads.txt. ID рекламного блока не заменяет эти строки.
3. Яндекс Android Rewarded ID, только если планируется этот формат.
4. Фактической ссылки на JOBA в поддерживаемом магазине для проверки приложения. Если приложение ещё не опубликовано, сначала требуется отдельный этап публикации; вымышленную ссылку указывать нельзя.
5. Готовности договорных и платёжных данных кабинетов — их проверяет владелец внутри кабинетов, секретные документы пересылать в чат не нужно.

Подробно куда заходить: [JOBA-advertising-next-steps.ru.md](JOBA-advertising-next-steps.ru.md). Проверка РСЯ и исправления: [JOBA-RSYA-audit-2026-10-29.ru.md](JOBA-RSYA-audit-2026-10-29.ru.md).

Получение идентификаторов не означает завершения SDK-интеграции, настройки согласий, проверки тестовых показов и серверных наград. APK сейчас не собирается.
