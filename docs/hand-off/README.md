Инструкция различает монетизацию (AdMob/РСЯ), рекламу на сайте и покупку трафика (Google Ads/Директ), содержит создание блоков, список передаваемых идентификаторов и шаги серверной проверки награды. Создание кабинетов само по себе не подключает SDK.

### Тестовая оплата, названия документов и PIN, 27 октября

Опубликован `d1b4304`: [успешное развёртывание](https://github.com/milaniumkz/services-marketplace/actions/runs/40501536033). В PIN-клавиатуре оставлены цифры без букв. В «Документах JOBA» типы оплаты, возврата, оферты, контактов и согласия на проверку имеют отдельные понятные названия. По явному запросу владельца включена имитация оплаты при отсутствии реального провайдера. Выбор тарифа → «Посмотреть условия» → галочка → «Продолжить оплату» создаёт тестовую подписку на 30 дней с правами текущей роли и экраном «Тестовая оплата прошла». Деньги не списываются. Записи имеют `is_test=true`, операция журнала — `test_purchase`, денежное движение — 0. Такие операции не доступны для денежных возвратов и не учитываются как оплаченные права в сводке монетизации. Повторная покупка того же действующего тестового тарифа не продлевает срок и не создаёт дубль. Цена и режим повторно проверяются сервером. Проверка личности по-прежнему обязательна.

Владелец управляет режимом в админке: «Подписка и реклама → Тестовая оплата». Для изменения нужно указать причину. Выключение прекращает тестовые подписки текущей страны, реальные подписки не затрагивает. Перед переходом на реальную оплату выключите тестовый режим; наличие подключённого платёжного провайдера также исключает тестовые предложения. Цены берутся из редактируемого каталога. При публикации сохранены действующие цены KZ: Стандарт — 500 ₸, Премиум — 700 ₸, Заказчик — 500 ₸. Цена заказчика в остальных странах ещё требует настройки в местной валюте.
