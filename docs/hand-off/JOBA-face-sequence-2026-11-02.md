# Пять кадров лица и исправление распознавания крупных селфи

Текущая версия снимает кадры автоматически: см. [обновление автофиксации](JOBA-automatic-face-capture-2026-11-02.md). Ниже описана предыдущая версия с ручными кнопками.

Последовательность для настройки и восстановления одинакова: прямо → немного налево → немного направо → посмотреть прямо и моргнуть → улыбнуться. После «Начать съёмку» озвучивается первая инструкция. На каждом шаге пользователь нажимает «Снять кадр и продолжить», после пятого — «Снять кадр и завершить». Все пять кадров обрабатываются сервером; только после успеха сохраняется зашифрованный набор шаблонов. Исходные фотографии не сохраняются.

Озвучка веб-версии использует Speech Synthesis браузера: русский язык, спокойный темп, предпочтение женскому голосу при наличии. Доступность и голос зависят от браузера/устройства. Звук можно выключить; текстовые подсказки остаются. При отмене голос и камера останавливаются. Движения автоматически не проверяются; защита от фотографий, записей, дипфейков и подмены потока по-прежнему не реализована по исходному требованию. Процедуру нельзя описывать как проверку живого присутствия.

Ошибка крупного селфи воспроизведена на тестовом снимке: при размере 1280/1600 пикселей лицо не находилось, при 320/640 — находилось. Детектор теперь работает на двух масштабах с объединением одинаковых обнаружений; точки лица переводятся обратно в исходный кадр. Порог детектора 0,9 и порог сравнения 0,45 не уменьшались. Нулевое и множественное обнаружения теперь имеют разные сообщения, а ошибка обработки называет конкретный шаг.

API требует все пять кадров в правильном порядке. Неполный/переставленный набор не принимается; разные лица в одном наборе не сохраняются. Ошибка оставляет прежний шаблон действующим. Существующим пользователям с одиночным шаблоном предлагается обновление; прежний шаблон пока совместим с новой пятикадровой проверкой. Новая запись заменяет старую только целиком, после успешной обработки всех кадров и нового согласия.

Для проверки на сайте: обновить страницу без очистки данных → Профиль → Безопасность → Восстановление по лицу → ввести текущий пароль, дать согласие и пройти пять шагов. После выхода два неверных пароля открывают такую же пятикадровую проверку. Проверить также отмену, отключение звука и отказ при неполном наборе. Чужие аккаунты для теста не использовать. APK не собирается.
