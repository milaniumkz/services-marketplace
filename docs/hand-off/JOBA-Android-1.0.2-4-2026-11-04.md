# Android 1.0.2 (4) — поиск и стабильность

## Изменения

- В поиске ближайших заказов используется общий с вебом `currentDeviceLocation`, вместо отдельного необработанного MethodChannel. Координаты не округляются до сотых; городской фильтр удаляется при выборе радиуса. Радиус заказов сохраняется 50 км.
- Системный запрос Android-геолокации относится к внешней операции текущего экрана и не запускает PIN при возврате. Время ожидания включает диалог разрешения. На отказ/неверные координаты запрос «все заказы» не подставляется.
- Android одновременно запрашивает GPS и сетевое положение через LocationManagerCompat, включая Android до 11. Пустой ответ одного источника не обрывает второй. Допускается только свежая последняя позиция (не более 2 минут); старая позиция/город вместо геолокации не используются. Запросы, таймер и cancellation очищаются после ответа или уничтожения Activity.
- Для нативного приложения баннер имеет постоянный ключ сессии и сохраняет один platform view при переключении разделов и временном скрытии на форме/с клавиатурой. При выходе из аккаунта уничтожается. Подготовка SDK выполняется до загрузки, поздние ответы старой сессии отбрасываются, ошибки асинхронного освобождения перехватываются.
- В Android выбран OpenGL/Skia вместо Impeller для совместимости с нативными рекламными/WebView-поверхностями. Аппаратное ускорение остаётся включено. Это мера совместимости, а не доказательство причины исходного падения.
- Crashlytics получает имя текущего экрана без содержимого полей. На Android 11+ при следующем запуске добавляется диагностика предыдущего завершения процесса через ApplicationExitInfo: причина, код и память. Нет фото, координат, токенов или переписки. Диагностика не блокирует вход. Историческая запись отправляется один раз.
- Сохранены платные функции, объявления, подписка за рекламу, приглашения, автоматическая биометрия и предыдущие исправления черновиков/фотографий. Версия повышена до 1.0.2 (4).

## Ограничения проверки

Исходного журнала Android с телефона нет, модель устройства пока не сообщена. В рабочем окружении нет подключённого телефона или Android-эмулятора с аппаратным ускорением. Исходное закрытие процесса не воспроизведено; нельзя утверждать, что установлена единственная причина и исключены все будущие вылеты. Добавленная диагностика позволит отличить падение, завершение по памяти и ANR после следующего запуска.

Тестовый APK использует прежний тестовый сертификат версии 1.0.1 (3), поэтому может обновить именно ту тестовую установку без удаления данных. Поверх приложения Play с другим сертификатом не устанавливается. Рабочий API — https://joba.com.kz. Публикация в магазине не выполняется.
