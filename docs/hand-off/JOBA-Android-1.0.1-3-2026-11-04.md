# JOBA для Android — версия 1.0.1 (3)

Изменения приложения: `89196248798f52d18f184b18cf9a7e0aa1b675e5`, ветка `Project/store-publication` (также `feat/joba-implementation`). Сайт и API опубликованы из `26e01f5e4dd98470f1a3b6f498268d80b3b12be1`: https://github.com/milaniumkz/services-marketplace/actions/runs/41789105284. Последующий коммит приложения уменьшает память миниатюр и обновляет подготовку зависимостей перед Android-сборкой.

## Что изменено

- В сборках магазина выключен прежний бесплатный режим. Вернулись «Мой доступ», управление подпиской, продление и смена тарифа, Топ-100, продвижение, приглашения и бонусы. При активной подписке название входа остаётся «Мой доступ». Серверные тарифы, права и действующий режим оплаты общие с веб-версией.
- Подключён нативный SDK Яндекса. Android-баннер: `R-M-20254161-1`, Android Rewarded: `R-M-20254161-3`. Баннер ограничен высотой 50 dp. На сервере включены обычные объявления и подписка за рекламу; подтверждены 5 завершённых просмотров отдельно для заказчика, Стандарта исполнителя и Топ-100, каждый на 30 дней. Числа и блоки редактируются в админке. Уже начатые наборы сохраняют исходные условия. Раннее закрытие ролика не добавляет просмотр, повтор подтверждения не дублирует награду.
- Возврат из камеры, галереи и рекламного плеера не считается уходом из приложения для автоматического PIN. При обычной разблокировке сохраняется прежний экран. Обновления событий не пересоздают экран редактирования фотографии во время операции.
- Ввод нового заказа сохраняется в зашифрованном хранилище устройства отдельно для каждого аккаунта UUID, страны и API. Он восстанавливается при повторном открытии создания заказа. После успешного создания серверного черновика локальный ввод очищается. Черновики разных аккаунтов, включая повторную регистрацию старого номера с новым UUID, не смешиваются.
- Камера/галерея ограничены разрешением 2048 px. Кэш декодированных изображений ограничен 48 MiB. Миниатюры декодируются под фактическую ширину своего блока: например, 100 dp при плотности 3 используют ширину 300 px вместо почти полноэкранного изображения. При нехватке памяти освобождается кэш, введённые данные сохраняются.
- Ручная предварительная проверка остаётся у документов. Заказы, услуги и портфолио публикуются без ожидания администратора после обязательных полей и действия публикации. Публичная видимость исполнителя требует одобренного документа. Предыдущая публичная редакция сохраняется, пока пользователь редактирует черновик. Жалобы, последующее скрытие нарушения и история редакций остаются доступны. Предыдущие заявки услуг/портфолио в `pending_review` переведены в публикацию, решения по жалобам не отменяются.
- По итоговому указанию владельца одобренное селфи становится фото профиля. Две страницы удостоверения приватны. В шаге селфи указано снять лицо без документа в кадре. Восстановление ранее отвязанных производных фото проверяет именно ссылку на селфи одобренной проверки, владельца и страну; страницы документа не назначаются аватаром.
- Увеличен слой адаптивной иконки с 46 до 72 dp и убран дополнительный отступ круглой иконки. Само изображение не перерисовывалось. Отображение проверено под круглой маской Android-лаунчера.
- В release-сборках подключён Firebase Crashlytics для диагностики Flutter и платформенных ошибок. Исторических журналов исходных падений с двух телефонов нет: исходный native crash на физическом устройстве не воспроизведён. Обнаруженные ошибки переходов и перерасход памяти исправлены; отсутствие любых будущих падений этим не доказывается.

## Как выпустить обновление в Play Маркете

1. На прежней машине с ключом подписи обновить `Project/store-publication` через `git pull --ff-only`. Для воспроизводимости использовать Flutter 3.35.7. Прежний ключ и его пароли не переносить в Git.
2. В корне проекта выполнить `python3 scripts/build-store-android.py`. Скрипт читает прежний закрытый файл `~/.joba-publication/android-signing.json` либо путь `JOBA_SIGNING_CONFIG`, обновляет зависимости и собирает подписанный AAB. Новый выпуск использует `JOBA_FREE_MOBILE=false`; старый флаг `true` не использовать.
3. В Play Console открыть JOBA → нужный трек тестирования или рабочий выпуск → создать выпуск и загрузить **вновь подписанный** `apps/mobile/build/app/outputs/bundle/release/app-release.aab`. Номер сборки — 3. Тексты обновления находятся в `store-assets/metadata/ru-RU.json`.
4. Указать наличие рекламы и актуализировать «Безопасность данных» и использование рекламного идентификатора с учётом нативного SDK Яндекса и Crashlytics. Далее отправить выпуск на проверку и распространение.
5. Новые функции появятся на телефонах после установки обновления. Журналы новой версии: Firebase → проект `joba-832c7` → Crashlytics → Android-приложение `kz.joba.services_marketplace`.

Совместимость: сервер временно сохраняет старый бесплатный канал для уже установленной версии 2, где нет кнопок оплаты. Новая версия этот канал не использует. Его отключение следует согласовать с распространением обновления. Для iOS нужны отдельные одобренные рекламные блоки iOS; Android-блоки туда не подставляются. Подпись/публикация в Play и проверка новой версии на физических телефонах в этой задаче не выполнялись по указанию владельца.
