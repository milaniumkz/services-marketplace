# Проверка документов, вложения поддержки и отправленные отзывы

## Добровольная проверка обеих ролей

В «Мой профиль» обеих ролей доступен пункт «Добровольная проверка документов». Проверка не блокирует работу с заказами и услугами; открытие пункта не создаёт заявку автоматически. Подтверждённый профиль получает синюю галочку возле имени. Для заказчика отметка также отображается исполнителю в заказе и приглашении. API возвращает только публичный флаг verified, без документов.

Проверка документов уже поддерживала заказчиков на сервере; ошибка была в скрытом для этой роли пункте меню и подписях, упоминавших только исполнителя. Настройки приватности теперь используют общее название. При проверке по-прежнему действуют региональные типы документов и требования к страницам; ручная проверка обеих сторон удостоверения не заменяется одной фотографией.

## Фото в переписке поддержки

Раньше input очищался после каждой попытки загрузки, включая неудачную. Ошибку затем перезаписывал таймер обновления переписки. Теперь выбранные файлы остаются в очереди и видимом списке, а ошибка сохраняется отдельно от времени обновления. «Повторить загрузку» продолжает оставшиеся файлы; уже обработанные вложения не загружаются повторно. Во время очереди отправка сообщения недоступна. Ненужный файл можно убрать. После успешной отправки поле и список очищаются. Фоновый ответ обновления, начавшийся до загрузки, не заменяет форму во время загрузки.

## Отзывы

Правило встречных отзывов сохранено: отзыв публикуется после встречного отзыва или окончания срока ожидания, при отсутствии ограничений по спору/модерации. Раньше раздел профиля показывал лишь полученные опубликованные отзывы, поэтому автор не находил свой отправленный отзыв. Теперь есть вкладка «Мои отзывы», где автор видит собственные отправленные отзывы, текст, статус и дату окончания ожидания. Карточка открывает собственный отзыв завершённого заказа. После отправки добавлена кнопка «Посмотреть мой отзыв».

API GET /users/{id}/reviews?direction=sent работает только для собственного id. Другому участнику и третьим лицам не раскрываются закрытые отзывы. Полученные отзывы и рейтинг продолжают учитывать только опубликованные видимые записи.

## Проверки

- Flutter: обе роли до/после верификации, открытие добровольной проверки без отправки заявки; отправленные отзывы, статус и открытие заказа; существующие квитанции действий.
- API: просмотр своего закрытого отзыва и отказ другому автору; ожидание публикации и блокировка спором; публичный флаг верифицированного заказчика без материалов документа; региональные страницы проверки и согласие.
- Chrome с изолированным реальным API: сетевой сбой выбора фото, сохранение имени файла и ошибки после автообновления, повтор загрузки, сохранение вложения при ручном обновлении, отправка и получение фотографии пользователем. Реальным пользователям тестовые сообщения не отправляются.

Веб-интерфейс и админка обновляются на сервере. Для новых пунктов и вкладок установленного нативного приложения нужен следующий выпуск. APK не собирается согласно действующему указанию. Платёжные системы и переключатели не изменяются.
