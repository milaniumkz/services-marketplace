# Автоматическая съёмка пяти шагов

После открытия фронтальной камеры кнопки съёмки и перехода скрыты. Браузер локально определяет точки лица и мимику и автоматически фиксирует шаги: нейтральное лицо прямо → немного налево → направо → прямо и моргнуть → улыбнуться. Для поворотов требуется стабильное положение; для моргания — последовательность «глаза открыты → оба закрыты → снова открыты»; для улыбки — изменение выражения относительно первого нейтрального кадра. Просто ожидание или неподвижное лицо не переводят шаги дальше.

После пятого кадра окно закрывается, сервер проверяет и сохраняет зашифрованный набор. Приложение показывает сообщение об успехе либо конкретную ошибку. При отмене или ошибке камера, определение движений и голос останавливаются; частичный набор не сохраняется. Сбой загрузки модели не заменяется ручной или таймерной съёмкой. При отсутствии прогресса процедура завершается понятной ошибкой через три минуты.

Озвучка начинается автоматически вместе с шагами. Фразы сокращены, темп изменён с 0,9 до 1,15, громкость — до 65%. Женский русский голос предпочитается при наличии на устройстве; звук можно выключить. Для первого шага нужно нейтральное лицо без улыбки, чтобы последняя улыбка определялась как новое выражение.

MediaPipe Tasks Vision 0.10.32 и Face Landmarker float16 v1 обслуживаются с домена JOBA. Версии, размер и SHA-256 каждого файла закреплены в `scripts/face-browser-assets.json`; архив npm также проверяется по SHA-512. Скрипт подготовки используется в CI и сборке. Лицензия/уведомление находятся в `apps/mobile/web/face-models/`. Браузер не отправляет видеопоток внешним сервисам: сервер JOBA получает только пять выбранных снимков. Исходные фото не сохраняются.

Определение движений — удобство автоматической съёмки. Это **не защита от фотографий, видео, дипфейков или подмены потока**. Сервер по-прежнему проверяет совпадение лица, но не получает доказательство подлинности движений. Калибровка на разных людях/устройствах ещё не выполнена. Проверка реальной модели в изолированном браузере использует только публичный тестовый портрет; она подтверждает получение точек/мимики, а не точность всех движений в реальных условиях.

Проверка пользователем: обновить страницу без очистки данных → открыть настройку лица или восстановление → разрешить камеру → следовать голосу без кнопок съёмки. На первом шаге расслабить лицо, затем немного повернуть голову в каждую сторону, вернуть прямо, закрыть и открыть оба глаза, улыбнуться. После последнего шага дождаться сообщения сервера. APK не собирается; обновляется веб-версия.
