Для владельца и сотрудников без технической подготовки. Редакция: 20 октября 2026 года.

## 2. Первый вход — пошагово

1. Откройте Chrome, Edge или другой современный браузер на компьютере. На большом экране управлять панелью удобнее.
2. Вставьте ссылку на админ-панель из раздела 1 в адресную строку браузера и нажмите Enter.
3. Найдите поле «Логин» и введите admin маленькими латинскими буквами.
4. В поле «Пароль» вставьте пароль из раздела 1. Не добавляйте пробел перед ним или после него. При вводе символы могут отображаться точками — это нормально.
5. В списке «Страна» выберите нужный регион: KZ — Казахстан, KG — Кыргызстан, RU — Россия, BY — Беларусь.
6. Нажмите «Продолжить» один раз и дождитесь открытия панели.
7. Убедитесь, что открылась страница обзора и доступно меню разделов. Запроса второго фактора быть не должно.

Если вы вошли не в ту страну, выйдите из аккаунта и войдите заново с другой страной. Открытие карточки по прямой ссылке само по себе не переключает регион.

Если браузер предлагает сохранить пароль, делайте это только на личном или защищённом рабочем компьютере. Завершайте работу кнопкой выхода из панели. Закрытие одной вкладки не заменяет выход из учётной записи.

## 3. Как устроена панель

Слева находится меню разделов. В основной части страницы — список записей, фильтры или карточка выбранной записи. В верхней части могут быть поиск, уведомления, название текущего раздела и кнопка обновления.

В разных разделах названия групп меню могут немного отличаться от заголовков страницы. Например, «Каталог цен» открывает тарифы и цены, а «Роли и сотрудники» — права доступа. В инструкции рядом с важными разделами приведены прямые ссылки. Открывайте их после входа в нужную страну.

**Карточка** — страница одного пользователя, заказа, обращения или настройки. **ID** — уникальный номер записи; его можно копировать для поиска и переписки с технической поддержкой. **Версия** — номер изменения записи: v1, v2 и далее. **Причина/основание** — объяснение вашего действия, которое попадёт в историю.

Пример хорошего основания: «Исправление адреса оператора по предоставленным регистрационным документам». Одного слова «правка» часто недостаточно: многие формы требуют не менее 10 символов.

## 4. Одинаковые действия в разных разделах

### Поиск и фильтры

1. Откройте нужный раздел.
2. Введите имя, название или ID. Для общего поиска используйте не менее двух символов.
3. При необходимости выберите статус, тип записи, город или период.
4. Нажмите «Найти» или «Применить» — в зависимости от формы.
5. Если результатов нет, проверьте страну, уберите лишние фильтры или нажмите «Сбросить».
6. Для следующей части списка нажмите «Следующая страница», если она доступна. Отсутствие этой кнопки означает, что загружен конец списка по выбранным фильтрам.

Глобальный поиск открывается нажатием на поиск в верхней панели или сочетанием Ctrl+K / Cmd+K. Выберите тип записи, введите запрос, нажмите «Найти» и откройте найденную карточку.

### Сохранение и публикация

1. Заполните поля формы. Поля со звёздочкой и поля, которые браузер подсвечивает при отправке, обязательны.
2. Укажите понятную причину изменения.
3. Нажмите кнопку сохранения один раз. Пока запрос обрабатывается, кнопка может быть временно недоступна.
4. Прочитайте результат на странице. Если показана ошибка, изменение не следует считать завершённым.
5. Нажмите «Обновить» и проверьте сохранённые значения.

Сохранить черновик и опубликовать — разные действия. Черновик нужен для подготовки; пользователи приложения начинают получать настройку после её публикации и вступления в силу.

### Публикация другим сотрудником

Для ряда важных настроек действует правило независимого подтверждения. Если кнопка называется «Опубликовать другим сотрудником», автор черновика не должен публиковать свою версию. Не пытайтесь обойти сообщение об ограничении повторными нажатиями: нужен другой уполномоченный сотрудник с отдельным аккаунтом. Суперадминистратор не отменяет автоматически это правило.

### Что означают состояния

| Состояние | Значение | Ваше действие |
| --- | --- | --- |
| Черновик / draft | Изменение подготовлено, но не действует | Проверьте значения и выполните предусмотренные проверки |
| Действует / effective | Версия опубликована и применяется | Меняйте её через новую версию |
| Запланировано | Изменение ожидает времени запуска | Проверьте дату, время и регион |
| Остановлено / stopped | Новое применение версии прекращено | Прочитайте последствия; ранее выданные права могут сохраниться |
| Заменено / superseded | Вместо версии действует более новая | Откройте актуальную версию |
| Архив | Запись сохранена для истории | Для изменения создайте новую активную версию |
| В очереди / выполняется | Задача ещё не закончена | Обновите страницу задачи позже |
| Ошибка / failed | Действие не завершилось успешно | Прочитайте причину; повторяйте только предусмотренным способом |

## 5. Обзор платформы и ежедневная работа

Прямая ссылка: https://joba.com.kz/admin/#dashboard

На странице обзора смотрите сводку текущего региона, блок «Требует внимания», показатели пользователей, заказов, обращений и сервиса. Если доступен выбор периода, задайте его перед сравнением показателей.

Рекомендуемый порядок каждый рабочий день:

1. Проверьте выбранную страну.
2. Откройте обзор и посмотрите, есть ли незавершённые задачи или проблемы.
3. Проверьте новые обращения поддержки.
4. Обработайте заявки на проверку личности и очередь модерации.
5. Проверьте заявки на возврат и запросы по персональным данным.
6. Просмотрите запланированные изменения и ошибки фоновых задач.
7. Если меняли настройки, проверьте журнал аудита и результат в приложении.

Нулевой показатель не обязательно означает неисправность. Например, до подключения платёжного провайдера реальных платежей и доходов может не быть.

## 6. Пользователи: найти человека и открыть его историю

Прямая ссылка: https://joba.com.kz/admin/#users

1. Введите имя или ID пользователя в поиск. Если есть фильтры роли и статуса, выберите нужные значения.
2. Нажмите «Найти».
3. Найдите нужную строку и откройте карточку.
4. Сверьте ID, имя, страну, город, роль и статус, чтобы не работать с однофамильцем.
5. Откройте связанные заказы, дела, обращения и хронологию, если нужно разобраться в ситуации.
6. Перед ограничением аккаунта прочитайте связанные материалы и историю решений.

Заказчик пользуется сервисом бесплатно. Подписка относится к возможностям исполнителя. Один человек может иметь обе роли; наличие роли заказчика не означает, что с него нужно брать плату.

Телефон и подробные сведения безопасности могут быть скрыты. Если для работы нужно раскрыть разрешённое поле, нажмите соответствующую кнопку. Причину указывать не требуется. Такой просмотр фиксируется. Открытие карточки пользователя не даёт права выгружать или распространять его персональные данные.

Для событий безопасности нажмите «Загрузить события». Основание заполняется автоматически. Не путайте город в профиле, который указал сам пользователь, с приблизительным регионом IP-адреса.

## 7. Заказы и отклики

Прямая ссылка: https://joba.com.kz/admin/#orders

1. Найдите заказ по ID, названию или доступным фильтрам.
2. Откройте карточку.
3. Проверьте заказчика, исполнителя, статус, сроки, содержание и связанные обращения.
4. Если нужна служебная операция, используйте только действие, которое предлагается в карточке для её текущего состояния.
5. Укажите основание, подтвердите действие и проверьте результат после обновления.

Статусы заказа отражают его жизненный цикл: опубликован, назначен, в работе, ожидает подтверждения завершения, завершён, отменён или истёк. Не меняйте состояние заказа ради исправления текста: модерация содержания и фактическое выполнение заказа — разные процессы.

Если пользователь сообщает об ошибке, попросите ID заказа и описание ситуации. Не создавайте вместо него случайный новый заказ для обхода ошибки.

## 8. Очередь модерации и дела

Прямая ссылка: https://joba.com.kz/admin/#moderation

1. Откройте дело из очереди.
2. Прочитайте материал, жалобу, текущую версию и предыдущие решения.
3. Если есть назначение ответственного, проверьте, что дело закреплено за нужным сотрудником.
4. Посмотрите доступные доказательства. Скрытые фотографии и защищённые поля открывайте соответствующей кнопкой без ввода причины.
5. Выберите доступное решение: например, разрешить материал, вернуть на исправление или отклонить. Точный список зависит от вида дела и состояния записи.
6. В объяснении для пользователя напишите, что именно нужно исправить. В служебном основании укажите, почему принято решение.
7. Сохраните решение и проверьте новый статус.

Если показано «Версия изменилась» или «Конфликт версии», обновите дело и заново просмотрите материал. Ваше решение не должно применяться к фотографии или тексту, которые автор уже заменил.

## 9. Проверка личности исполнителя

Прямая ссылка: https://joba.com.kz/admin/#verification

1. Найдите заявку, которая ожидает решения, и откройте её.
2. Проверьте пользователя, тип документа и номер ревизии.
3. Для просмотра документа нажмите «Открыть документы». Фотографии и селфи также загружаются автоматически, если ваша роль разрешает просмотр.
4. Изучите доступные материалы в защищённом просмотре.
5. В блоке «Решение по проверке» выберите решение и нажмите «Сохранить решение». Ручное основание не требуется; подтверждение бессрочно до ручного отзыва.
6. Нажмите «Сохранить решение».
7. Обновите карточку и убедитесь, что статус изменился.

Не скачивайте документы на личный компьютер и не отправляйте их в мессенджеры. Не подтверждайте личность по просьбе пользователя без проверки материалов. При необходимости исправления объясните конкретную причину понятным языком.

## 10. Портфолио и профили исполнителей

Ссылки: https://joba.com.kz/admin/#portfolio и https://joba.com.kz/admin/#contractors

В портфолио проверяются проекты и фотографии, в профилях исполнителей — сведения об услугах.

1. Найдите материал и откройте его карточку.
2. Сверьте автора, страну, категорию, текст и текущую ревизию.
3. Для защищённых фотографий заполните причину и нажмите «Показать фотографии».
4. Примите доступное решение по модерации и заполните основание.
5. Проверьте состояние после сохранения.

Активная подписка не отменяет правила модерации и проверку личности. Премиум не делает скрытый, отклонённый или заблокированный профиль публичным автоматически.

## 11. Поддержка: прочитать обращение и ответить

Прямая ссылка: https://joba.com.kz/admin/#support

1. Откройте список обращений и примените нужные фильтры.
2. Выберите обращение по ID или теме.
3. Прочитайте всю переписку и связанные сведения, чтобы не просить пользователя повторять уже предоставленную информацию.
4. Если доступно назначение ответственного, назначьте сотрудника и укажите причину.
5. Напишите ответ в поле сообщения и отправьте его.
6. Убедитесь, что сообщение появилось в переписке.
7. После фактического решения вопроса выполните доступную команду закрытия или изменения состояния.

Ответ пользователю и внутренняя заметка — разные вещи. Внутренняя заметка предназначена для сотрудников и не заменяет отправленный ответ. Не помещайте в обычное сообщение пароль суперадминистратора, документы или платёжные секреты.

Если запрос был отправлен, а страница показала сетевую ошибку, сначала обновите переписку. Не отправляйте одинаковое сообщение много раз, не проверив, появился ли первый ответ.

## 12. Восстановление доступа без входа

Прямая ссылка: https://joba.com.kz/admin/#support-recovery

Этот раздел предназначен для обращений людей, которые не могут войти в приложение.

1. Откройте обращение.
2. Прочитайте описание проблемы и предыдущие сообщения.
3. Если доступно, назначьте ответственного с указанием основания.
4. Ответьте через форму сообщения.
5. Выполните предусмотренную процедуру проверки принадлежности аккаунта; одного заявления «это мой номер» недостаточно.
6. Зафиксируйте принятое решение и результат.

Наличие обращения не означает автоматического разрешения на смену владельца аккаунта или передачу чужих данных. Вопросы, для которых нет подходящего действия в форме, передавайте техническому ответственному вместе с ID обращения.

## 13. Чёрный список, ограничения и апелляции

Прямая ссылка: https://joba.com.kz/admin/#blacklist

1. Найдите пользователя и связанное дело.
2. Откройте ограничение или форму его назначения.
3. Выберите доступный вид ограничения.
4. Укажите основание и конечный срок, если это предусмотрено формой.
5. Проверьте, какие именно действия будут ограничены.
6. Подтвердите операцию и проверьте её результат.

Ограничение не равнозначно удалению аккаунта. Не используйте бессрочное ограничение вместо разбора обычной жалобы. При апелляции просмотрите исходное дело, доводы пользователя и историю, затем сохраните отдельное решение по апелляции с причиной.

Для массового действия сначала формируется список, затем рассчитывается влияние и подтверждается зафиксированный состав. Некоторые операции требуют другого сотрудника. Если результат частичный, проверьте каждую ошибку и повторяйте только разрешённую часть — не весь исходный список без разбора.

## 14. Словари запрещённых слов и проверка правил

Прямая ссылка: https://joba.com.kz/admin/#dictionary

1. Создайте новый черновик или копию существующей версии.
2. Добавьте правило: выражение и поддерживаемый способ совпадения.
3. Проверьте, не содержит ли правило слишком распространённое слово, из-за которого будут задерживаться нормальные материалы.
4. Сохраните черновик с причиной.
5. Нажмите «Проверить» и выполните «Предпросмотр правил».
6. Проверьте текст на конкретных примерах в разделе проверки словаря.
7. Передайте версию другому уполномоченному сотруднику для публикации.

Проверка на примере показывает, как правило сработает; она сама по себе не публикует словарь. Для ошибочно опубликованного набора используйте остановку или копию/новую исправленную версию, а не попытку переписать историю.

## 15. Категории услуг, переводы и поля заказа

Прямая ссылка: https://joba.com.kz/admin/#categories

1. Откройте категорию или подготовьте новую версию каталога.
2. Заполните названия на нужных языках и положение категории в дереве.
3. При необходимости добавьте дополнительные поля заказа через «Добавить поле». Определите название, тип и обязательность каждого поля.
4. Сохраните версию с основанием.
5. Нажмите «Проверить дерево и поля», затем «Предпросмотр».
6. Исправьте ошибки, если они показаны.
7. Попросите другого уполномоченного сотрудника опубликовать версию.

Перед архивированием категории посмотрите, используются ли в ней действующие услуги и заказы. Черновик отката — это новый проект изменения, а не мгновенное возвращение старой версии.

Раздел языков показывает поддерживаемую локализацию. Заполнение перевода названия категории не переводит автоматически весь интерфейс и все пользовательские тексты.

| Тариф | Срок | Что получает исполнитель |
| --- | --- | --- |
| Стандарт | 30 дней | Доступ к поиску заказов, откликам и публикации услуг |
| Премиум | 30 дней | Возможности Стандарта и приоритет услуг в Топ-100 |

Срок — 30 суток, а не произвольный календарный месяц. Права появляются после подтверждения оплаты. Простое сохранение цены или нажатие кнопки в приложении не означает, что платёж прошёл.

В Топ-100 сохраняются ограничения по региону, фильтрам, публикации, проверке личности и модерации. Премиум даёт приоритет подходящим услугам; порядок внутри списка определяется правилами рейтинга. Список содержит до 100 результатов для выбранных условий. Премиум не обещает гарантированного первого места, количества заказов или дохода.

Когда срок права заканчивается либо право отзывается после возврата, премиальный приоритет перестаёт действовать. Обычная публикация профиля и его видимость также зависят от состояния аккаунта и правил сервиса.

Начальные цены по указанию владельца: Стандарт — 1 000, Премиум — 1 500 в местной валюте каждой страны. Их можно менять отдельно по странам. До подключения платёжного провайдера реальные продажи недоступны. Не вписывайте вымышленный платёжный провайдер, чтобы обойти это ограничение.

## 17. Как установить или изменить цену подписки

Прямая ссылка: https://joba.com.kz/admin/#pricing

### Изменить отображаемую базовую цену

1. Войдите в нужную страну и откройте «Каталог цен».
2. В верхнем блоке «Стандарт и Премиум · 30 дней» найдите поля обоих тарифов.
3. Введите суммы в местной валюте. Начальные значения — 1000 и 1500.
4. Заполните «Причина изменения» и нажмите «Сохранить цены тарифов».
5. Обновите страницу и убедитесь, что суммы сохранены.
6. Проверьте цены в приложении под ролью исполнителя. Изменение относится только к текущей стране.

Этот блок работает до подключения оплаты. После подключения провайдера новая сумма должна быть также подтверждена соответствующим платёжным продуктом: предложение со старой неподходящей суммой не должно продолжать продаваться. Уже оплаченные покупки сохраняют свои условия.

### Подготовить реальное платёжное предложение

1. Войдите в нужную страну. Валюта определяется страной: KZT, KGS, RUB или BYN.
2. Откройте «Каталог цен» и нажмите «Новая версия цены».
3. Введите понятное название, например «Стандарт — 30 дней».
4. В поле «Продукт» выберите «Подписка исполнителя».
5. В поле «Тариф подписки» выберите «Стандарт» или «Премиум».
6. Введите цену в валюте страны. Если поле принимает дробную часть, используйте до двух знаков после запятой/точки.
7. Проверьте срок: для этих тарифов он фиксирован — 30 дней.
8. Введите код реально подключённого платёжного провайдера и идентификатор продукта / SKU, полученный при настройке оплаты.
9. Напишите причину изменения и сохраните черновик.
10. Откройте сохранённую версию и выполните «Проверить синхронизацию».
11. Нажмите «Предпросмотр влияния» и прочитайте результат.
12. После успешной проверки другой уполномоченный сотрудник публикует версию.
13. Проверьте предложение в приложении под ролью исполнителя.

Повторите настройку для второго тарифа и для других стран. Используйте разные идентификаторы продуктов для разных тарифов. Остановка продажи версии не должна считаться автоматической отменой уже оплаченного доступа. У подтверждённой покупки сохраняется снимок условий на момент оплаты.

Если провайдер ещё не подключён, сохранение черновика может быть доступно, но проверка и публикация продажи будут ограничены. Это ожидаемый результат, а не повод подменять реальные платёжные данные.

## 18. Бесплатный промо-период подписки

Прямая ссылка: https://joba.com.kz/admin/#promo

Промо — отдельная временная акция, а не изменение постоянной цены тарифа.

1. Откройте раздел промо-периода.
2. Подготовьте черновик с названием, условиями, датами и целевой аудиторией.
3. Проверьте часовой пояс и границу окончания. Если форма показывает UTC, время указано по всемирному времени; в Казахстане и Кыргызстане часы могут отличаться.
4. Выберите следующий опубликованный платный тариф, когда это требует форма.
5. Сохраните, проверьте и откройте предпросмотр условий для пользователя.
6. Проверьте, что обещанный бесплатный период и условия после его окончания понятны.
7. Передайте версию на независимую публикацию.

Не обещайте автоматическое платное списание, если соответствующая платёжная интеграция не подключена и согласие пользователя не предусмотрено действующей схемой оплаты.

## 19. Платежи, финансовый журнал и возвраты

Ссылки: https://joba.com.kz/admin/#financial-journal и https://joba.com.kz/admin/#refunds

### Проверка платежа

1. Найдите платёж по доступным фильтрам, ID или пользователю.
2. Сверьте страну, валюту, сумму, идентификатор операции, состояние и связанный доступ.
3. Если платёж ожидает подтверждения, сначала проверьте состояние обработки. Не просите пользователя повторно платить без выяснения результата первого платежа.
4. Не считайте надпись в браузере или присланный скриншот достаточным доказательством зачисления. Рабочее подтверждение приходит от платёжной системы.

### Заявка на возврат

1. Откройте заявку и прочитайте причину.
2. Проверьте исходный платёж и доступный остаток для возврата.
3. Выберите только доступное действие для текущего статуса заявки.
4. Заполните требуемые поля, сумму и основание, если они предусмотрены.
5. Проверьте последствия для доступа пользователя.
6. Подтвердите решение и, когда доступно и нужно, отправьте операцию провайдеру.
7. Проверьте итоговый статус и сверку результата. Решение администратора и фактическое перечисление денег — разные этапы.

До подключения платёжного провайдера реальные списания и банковские возвраты невозможны. При частичном возврате не возвращайте повторно сумму, которая уже была возвращена.

## 20. Подписка и реклама: общие переключатели

5. Укажите основание, сохраните черновик и выполните доступные проверки/предпросмотр.

До подключения рекламной сети и серверного подтверждения просмотров награды не выдаются как реальные. Ввод рекламного ID сам по себе не подключает SDK и проверку просмотра. Подробная настройка кабинетов Google и Яндекса описана в отдельной инструкции владельцу по рекламе.

## 26. Правовые документы и реквизиты

Прямая ссылка: https://joba.com.kz/admin/#legal

Доступны типы документов: конфиденциальность, условия использования, условия оплаты, возврат и отмена, публичная оферта, реквизиты и контакты, а также дополнительные типы правил.

### Как заполнить реквизиты

1. Войдите в Казахстан, если готовите документы для казахстанского оператора и банка.
2. Откройте «Правовые документы».
3. В блоке «Новый черновик» выберите «Реквизиты и контакты» и нужный язык.
4. Введите полное наименование ИП/ТОО или владельца, БИН/ИИН, юридический адрес, контактный email и другие обязательные сведения вашей деятельности.
5. Укажите причину создания и нажмите «Создать черновик».
6. Проверьте текст. Уполномоченный другой сотрудник публикует подготовленную версию по правилам системы.
7. Откройте публичную страницу и проверьте опубликованный текст.

### Как изменить существующий документ

1. Найдите нужный тип, язык и версию.
2. Раскройте «Текст документа» и прочитайте действующую редакцию.
3. Нажмите «Редактировать новой версией».

5. Создайте черновик, проверьте и передайте на публикацию.

По предыдущему решению владельца реквизиты в первоначальных документах оставлены незаполненными. Их нужно заполнить реальными данными перед коммерческим использованием. Страницы оплаты должны ясно объяснять, что покупает исполнитель, срок 30 дней, цену, порядок активации и возврата. Наличие страниц не является гарантией одобрения банка: ВТБ может запросить собственные дополнения и документы.

7. Заполните «Основание изменения» и нажмите «Сохранить роль».
8. Откройте роль из списка и проверьте отмеченные функции.

Флажок возле названия блока может выбрать сразу несколько действий. Перед сохранением просмотрите каждую галочку: разрешение «просмотр» не равнозначно разрешению «изменять» или «публиковать».

### Назначить роль

1. В блоке «Назначение сотруднику» выберите отдельную служебную учётную запись.
2. Отметьте нужную роль или несколько ролей.
3. Укажите основание назначения.
4. Нажмите «Применить роли сотрудника».
5. Попросите сотрудника войти под своим логином и проверить нужные разделы.

Важно: эта форма назначает роли уже существующей служебной учётной записи. Она не создаёт новый логин и пароль. Первичное создание аккаунта сотрудника пока выполняется отдельной защищённой процедурой техническим ответственным. Если список пуст, сначала нужно создать такую учётную запись.

Пустой выбор ролей при сохранении отзывает доступ к функциям. Назначение заменяет прежний набор ролей; проверьте все галочки, прежде чем сохранять.

### Изменить или отозвать права

Откройте роль, измените функции, укажите основание и сохраните. Изменения проверяются сервером при следующих запросах сотрудника. Архивирование роли отзывает её права; перед архивированием проверьте, кто ею пользуется. Аккаунт владельца нельзя понизить через обычное назначение ролей.

Для независимой публикации важных настроек подготовьте как минимум ещё одного уполномоченного сотрудника. Общий пароль admin не заменяет второго сотрудника.

## 30. Настройки платформы: лимиты и сроки

Прямая ссылка: https://joba.com.kz/admin/#settings

Здесь находятся сроки заказов и откликов, ограничения файлов и портфолио, параметры сессий, срок кэша конфигурации, настройки рейтинга и другие числовые значения текущей страны.

1. Найдите нужное поле по названию.
2. Прочитайте единицу измерения: секунды, минуты, часы, дни, МБ или количество.
3. Зафиксируйте прежнее значение в служебной записи.
4. Введите новое значение.
5. Заполните «Причина изменения» и нажмите «Сохранить настройки».
6. Обновите страницу и проверьте сохранённое значение.
7. Проверьте связанное поведение в приложении.

Не путайте секунды с минутами: 300 секунд — это 5 минут. Не устанавливайте 0, если не понимаете смысл нулевого значения. Технические сроки сессий и внутренние параметры лучше менять совместно с техническим ответственным.

## 32. Фоновые задачи, расписание и повторная обработка

Ссылки: https://joba.com.kz/admin/#jobs и https://joba.com.kz/admin/#scheduled

Фоновая задача — работа, которая выполняется не мгновенно: экспорт, удаление, обработка файла, рассылка или массовая операция.

1. Найдите задачу по ID и откройте карточку.
2. Прочитайте тип, состояние, время, число попыток и причину ошибки.
3. Если задача ещё выполняется, обновите её позже.
4. Если доступна кнопка проверки повтора, сначала нажмите «Проверить повтор».
5. При разрешённом повторе нажмите «Поставить повтор в очередь».
6. Проверьте результат новой попытки.

Повтор не должен выполняться бесконечно. Если ошибка связана с неподключённым провайдером, повтор без подключения её не устранит. В разделе расписания сверяйте дату и часовой пояс; отмена будущей операции не отменяет уже выполненную.

## 33. Аудит, безопасность и аналитика

Ссылки: https://joba.com.kz/admin/#audit, https://joba.com.kz/admin/#security и https://joba.com.kz/admin/#analytics

**Аудит** отвечает на вопросы: кто, когда, что изменил и на каком основании. Для разбирательства найдите запись по доступным фильтрам и сохраните ID действия. История действий не предназначена для редактирования или удаления обычными операциями.

**События безопасности** показывают входы и изменения доступа. Полные данные раскрывайте только через разрешённую форму с причиной. Не делайте вывод о личности человека только по IP-адресу.

**Аналитика** показывает агрегированные показатели выбранной страны и периода. Используйте блок определений, чтобы понимать, что именно считается. Количество операций, рекламный доход и реальные банковские поступления могут рассчитываться по разным источникам. Экспорт сводки не следует считать выпиской банка.

## 34. Что пока зависит от внешних подключений

| Возможность | Что уже можно готовить | Что требуется для реального выполнения |
| --- | --- | --- |
| Стандарт и Премиум | Цены 1000/1500, их редактирование, права, 30-дневный период | Платёжный провайдер, синхронизация продукта и проверка оплаты |
| Возврат денег | Заявки и служебное рассмотрение | Подключённая платёжная система и подтверждённая операция |
| Баннеры | Материалы, размещения и конфигурации | Рекламная сеть, SDK/адаптер и разрешённые блоки |

Не трактуйте статус черновика или наличие формы как подтверждение фактической оплаты, доставки push или одобрения банка.

## 35. Частые проблемы — что делать

| Ситуация | Что проверить и сделать |
| --- | --- |
| Не входит в админку | Проверьте ссылку, admin, пароль без пробелов, выбранную страну и раскладку; используйте копирование |
| Появляется старый экран со вторым фактором | Откройте ссылку из раздела 1 и обновите Ctrl+Shift+R; при повторении передайте техническому ответственному адрес страницы |
| Видна Сербия | Откройте текущий адрес веб-приложения и обновите страницу; рабочая страна — KG, Кыргызстан |
| Список пуст | Проверьте страну, поиск, фильтры и наличие реальных записей |
| Нет нужного раздела | Проверьте назначенную роль; владелец может выдать конкретные права |
| Недостаточно прав | Не повторяйте операцию; обратитесь к владельцу с названием раздела и нужного действия |
| Требуется другой сотрудник | Черновик должен подтвердить другой уполномоченный аккаунт; создайте/подключите сотрудника и назначьте роль |
| Версия изменилась | Обновите карточку, сравните текущие данные и повторно примите решение |
| Сессия завершена | Войдите заново; перед повторной отправкой проверьте, не сохранилась ли первая операция |
| Цена не публикуется | Проверьте провайдера, SKU, сумму, валюту, тариф, успешную синхронизацию и независимое подтверждение |
| Платёж не активировал доступ | Проверьте подтверждённый статус операции; не создавайте повторный платёж без проверки |
| Push не пришёл | Проверьте Firebase, устройство, согласие, аудиторию, расписание и итог задачи |
| Файл не принимается | Проверьте формат, размер и статус проверки; не переименовывайте запрещённый файл ради обхода |
| Задача завершилась с ошибкой | Откройте причину; выполните разрешённый повтор либо передайте ID ответственному |
| Страница не загружается | Проверьте интернет и адрес; попробуйте обновление и другой браузер, затем сообщите время и точную ссылку |

Для сообщения об ошибке подготовьте: страну, раздел, точную ссылку, ID записи, что нажали, ожидаемый результат, фактический текст ошибки, дату и время. Скриншот делайте без паролей, документов и открытых персональных данных.

## 36. Проверка перед завершением работы

1. Убедитесь, что подготовленные изменения действительно сохранены.
2. Отделите опубликованные версии от черновиков, которые ещё ждут согласования.
3. Проверьте, что пользователи получили отправленные ответы, а важные задачи имеют итоговый результат.
4. Для изменений документов и тарифов проверьте результат в публичной части или в приложении.
5. Не оставляйте открытыми документы пользователей и временные защищённые просмотры.
6. Нажмите выход из панели.
7. Уберите этот файл с паролем из общедоступных папок и общих чатов.
