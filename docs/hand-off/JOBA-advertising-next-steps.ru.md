## 1. Проверка файла на сайте

Адрес файла: https://joba.com.kz/app-ads.txt . Оба файла опубликованы и проверены 29.10.2026 в 16:46 по Екатеринбургу: HTTP 200, text/plain, точная строка владельца. Для сайта доступен отдельный файл https://joba.com.kz/ads.txt с той же полученной строкой Google.

Откройте оба адреса. На экране должна быть обычная строка Google, без интерфейса JOBA, авторизации и HTML-страницы. Файл размещает разработчик; загружать его через рекламный кабинет не требуется.

## 2. Запустить проверку app-ads.txt в AdMob

1. Откройте https://admob.google.com/ под владельцем аккаунта.
2. Слева нажмите **«Приложения» → «Все приложения»**.
3. Откройте вкладку **app-ads.txt**.
4. Найдите JOBA. Откройте её статус/сведения.
5. Если доступна кнопка повторной проверки/обновления, нажмите её.
6. Дождитесь повторного сканирования Google. Статус не меняется мгновенно; обновление может занять сутки или больше.
7. Передайте разработчику итоговый статус или точный текст ошибки. Если файла не находят, проверьте шаг 3.

## 3. Проверить магазин и сайт разработчика

Google должен связать JOBA с её реальной карточкой в поддерживаемом магазине и обнаружить сайт разработчика.

1. В AdMob откройте **«Приложения» → JOBA → «Настройки приложения»**.
2. Проверьте сведения о магазине. Если предлагается **«Добавить магазин» / добавление ссылки**, откройте этот пункт.
3. Укажите реальную опубликованную карточку JOBA из поддерживаемого сетью магазина.
4. Проверьте Android package name: `kz.joba.services_marketplace`.
5. В сведениях разработчика/контактах опубликованной карточки магазина сайт должен указывать на согласованный домен `https://joba.com.kz`.
6. Если карточки магазина ещё нет, сообщите об этом разработчику: сначала понадобится отдельный этап публикации приложения. Сайт JOBA, ссылка Firebase и скачивание тестового APK не заменяют карточку магазина.

## 4. Проверить готовность аккаунта Google

1. В AdMob откройте **«Центр правил»**. Проверьте предупреждения по аккаунту и JOBA.
2. Откройте **«Платежи»**. Проверьте незавершённые запросы подтверждения и данные получателя дохода, которые требует кабинет.
3. Передайте только результат: например, «готово», «ожидает проверки» или текст ограничения. Банковские документы и подтверждения личности загружайте непосредственно в Google, а не в общий чат.
4. Не пополняйте кампании Google Ads ради получения дохода от AdMob: это разные задачи и кабинеты.

Созданный рекламный блок сам по себе не подтверждает одобрение приложения или готовность выплат.

## 5. Реклама с вознаграждением

Google Rewarded ID и Яндекс Android Rewarded `R-M-20254161-3` уже получены. Сейчас владельцу не требуется придумывать callback URL.

Разработчик должен реализовать серверную проверку подписи Google и защиту от повторной выдачи награды, затем передать окончательный HTTPS SSV URL. После этого:

1. В AdMob открыть **«Приложения» → JOBA → «Рекламные блоки»**.
2. Выбрать блок **«С вознаграждением»** с ID `ca-app-pub-5590941579295248/6068875357`.
3. Найти **Server-side verification / «Серверная проверка»**, в том числе в расширенных настройках.
4. Ввести выданный разработчиком URL, выполнить доступную проверку, сохранить.

До получения URL этот пункт оставьте для последующего подключения. Правило и размер награды должны совпадать с серверными настройками JOBA.

## 6. Что ещё передать из Яндекса

Известны приложение №20254161, Android-баннер `R-M-20254161-1` и Android Rewarded `R-M-20254161-3`.

1. Открыть https://partner.yandex.ru/ → **«Реклама в приложениях» → JOBA**.
2. Над списком блоков нажать **«Добавить ссылку»** в предупреждении о тестовом статусе. Добавить реальную карточку JOBA в поддерживаемом магазине. Если приложение не опубликовано — сообщить об этом, не вводить чужую/несуществующую ссылку.
3. Rewarded уже создан: `R-M-20254161-3`, JOBA_Android_Rewarded, активен. Повторно создавать и присылать ID не требуется.
4. Скопировать из настроек/инструкции площадки точные строки Яндекса для **app-ads.txt**. Если не находятся, спросить поддержку: «Где взять строки app-ads.txt для приложения JOBA, ID 20254161?»
5. Для серверной выдачи награды запросить у поддержки документацию по подтверждению rewarded-награды сервером и передать ответ разработчику.
6. В **«Документы» / «Настройки»** проверить анкету, договор и данные получателя выплат; передать статус незавершённых проверок.

Строки Яндекса разработчик добавит в тот же app-ads.txt рядом с Google. Не заменяйте Google строкой Яндекса.
