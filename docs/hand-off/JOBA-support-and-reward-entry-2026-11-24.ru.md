# Поддержка и заметная подписка за рекламу

В «Доступ к JOBA» рекламная подписка выделена синей рамкой и светлым фоном. Для каждого предложения есть крупная синяя кнопка: «Смотреть рекламу», «Продолжить просмотр» либо «Получить доступ». Рядом остаются число завершённых просмотров и срок 30 дней. Подписка и отдельный Топ-100 открывают соответствующий прежний сценарий; деньги и условия начисления не меняются. Новые подписи переведены на казахский, кыргызский и белорусский.

В админке: «Поддержка» → «Написать пользователю» → найти получателя → выбрать → написать сообщение/прикрепить фото → «Отправить сообщение». Также кнопка доступна в карточке пользователя. Открытие формы ничего не отправляет. Пользователь получает переписку в существующем разделе поддержки; обновление установленного приложения для получения сообщений не требуется. Ответ из другой страны приходит в уведомления назначенного администратора в его регионе; открытие переписки снимает отметку непрочитанного и у таких уведомлений.

В списке обращений видны имя автора и последние цифры номера. Поиск работает по теме, имени и ID пользователя. В переписке показаны имя, страна, город, роли и ссылка на аккаунт. Кнопка «Показать номер» доступна при наличии права просмотра контактов; полный номер раскрывается отдельным аудируемым запросом, без расширения прав сотрудников. Для начала переписки ограниченным сотрудникам нужны права создания обращения и выбора пользователя; для вложений — загрузка файлов.

Дата сообщений и последняя активность отображаются по Астане (Asia/Almaty, UTC+5). Время подписано и помещается на мобильном экране; служебный ISO-формат не показывается пользователю админки.

Рамка и кнопки используют общий компонент для веба и нативного приложения. В вебе появляются после развёртывания. В уже установленном нативном APK оформление изменится только с отдельной новой сборкой. APK в рамках этой задачи не собирается. Банковские настройки и переключатели оплаты/рекламных подписок сохраняются.

Проверки выполняются с изолированной базой и тестовыми участниками. Реальным пользователям тестовые сообщения не отправляются.
