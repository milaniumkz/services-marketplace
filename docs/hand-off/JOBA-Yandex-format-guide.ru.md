# JOBA: какой рекламный блок выбирать в Яндексе

## Главное различие

| Где показывается реклама | Нужный формат | Что уже есть |
|---|---|---|
| Обычный баннер в браузере | «Реклама на сайтах» → «Баннер» | `R-A-20302217-1`, код получен |
| Обычный баннер в Android | «Реклама в приложениях» → «Баннер» | `R-M-20254161-1` |
| За просмотр рекламы в Android выдаётся внутренний бонус | «Реклама в приложениях» → «С вознаграждением» / Rewarded | Получен `R-M-20254161-3`, JOBA_Android_Rewarded |
| За просмотр рекламы в браузере выдаётся внутренний бонус | Специальный поддерживаемый Rewarded-формат | В присланном списке форматов сайтов отсутствует; доступность уточняется у РСЯ |

«Полноэкранный», Floor Ad, Top Ad, Overlay, In-Image и «Лента» не заменяют формат с вознаграждением. Наличие видео в обычном блоке тоже не делает его Rewarded.

## Блок с вознаграждением для Android уже получен

На последнем скриншоте создан **JOBA_Android_Rewarded**, ID **`R-M-20254161-3`**, статус «Активно». Он выбран основным. На итоговом скриншоте владелец оставил два активных блока: `R-M-20254161-1` (баннер) и `R-M-20254161-3` (Rewarded). `R-M-20254161-2` больше не показан в активном списке. Повторно создавать блоки не нужно. Ниже сохранены шаги создания для справки.

## Как создаётся блок с вознаграждением для Android

1. Откройте https://partner.yandex.ru/ и войдите в существующий кабинет владельца JOBA.
2. В левом меню нажмите **«Реклама в приложениях»**. На присланном скриншоте выбран другой раздел — **«Реклама на сайтах»**.
3. Найдите приложение **JOBA**, ID **20254161**. Не создавайте его повторно.
4. Откройте карточку приложения.
5. Нажмите **«Добавить блок»**.
6. В списке форматов выберите **«С вознаграждением»** / **Rewarded**. Если его нет, не выбирайте вместо него «Баннер» или обычную межстраничную рекламу: передайте разработчику скриншот списка форматов именно приложения.
7. Введите понятное название **JOBA_Android_Rewarded**.
8. Сохраните блок кнопкой **«Создать»** или **«Сохранить»**, как она называется в вашем интерфейсе.
9. Откройте полученную карточку и скопируйте **ID рекламного блока**. Нужен именно новый Rewarded ID, а не ID приложения и не уже имеющийся баннер `R-M-20254161-1`.
10. Передайте ID текстом разработчику. Пароль кабинета, банковские реквизиты и коды входа для этого не требуются.

Внутреннее вознаграждение JOBA определяется настройками сервиса и подтверждённым завершением просмотра. Награда за клики по рекламе не назначается; закрытие ролика до завершения не должно выдавать бонус.

## Обычный баннер для браузера

1. В левом меню откройте **«Реклама на сайтах»**.
2. Откройте **joba.com.kz**.
3. Для нового обычного блока нажмите **«Добавить блок» → «Баннер»** — первая карточка присланного экрана.
4. Для JOBA создавать его снова не нужно: блок **`R-A-20302217-1`** и его код уже переданы.
5. По последнему сообщению владельца сайт одобрен после обращения в поддержку. Повторная модерация сейчас не требуется.

Одобрение сайта и создание блока не означают, что показы уже включены в коде приложения. Подключение и проверка отображения — задача разработчика.

## Вознаграждение в браузере

Среди показанных форматов сайтов нужного блока нет. Не создавайте «Полноэкранный» в надежде использовать его как Rewarded.

Откройте поддержку РСЯ в кабинете через значок помощи/обращения; расположение пункта зависит от версии интерфейса. Отправьте вопрос:

> Для сайта joba.com.kz, площадка 20302217, нужен формат Rewarded: пользователь добровольно смотрит рекламу и после завершённого просмотра получает внутренний бонус сервиса. Доступен ли этот формат для нашей площадки? Если да, где создать блок и какую документацию использовать?

Передайте разработчику ответ поддержки и документацию. До подтверждения нельзя обещать работу браузерного Rewarded через обычный баннер.

## Дополнительно для кабинетов

Если Яндекс показывает строки для ads.txt/app-ads.txt, скопируйте весь предлагаемый текст разработчику. Google-файлы уже опубликованы на https://joba.com.kz/ads.txt и https://joba.com.kz/app-ads.txt — не заменяйте существующие строки самостоятельно.

Если приложение в РСЯ остаётся в тестовом статусе и кабинет требует ссылку на магазин, нужна фактическая карточка опубликованного JOBA. Сайт и скачивание тестового APK не заменяют такую карточку.


По итоговому скриншоту блоки активны, однако само приложение остаётся в тестовом статусе: кабинет просит добавить фактическую ссылку на опубликованное приложение. Одобрение сайта РСЯ не снимает эту отдельную проверку Android-приложения.
