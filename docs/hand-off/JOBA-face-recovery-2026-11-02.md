# Восстановление пароля по лицу

Актуальная процедура из пяти кадров и исправление крупного селфи описаны в [обновлении последовательности](JOBA-face-sequence-2026-11-02.md). Ниже сохранены сведения о первой публикации.

На следующем полном входе или разблокировке сохранённой сессии обычному пользователю без шаблона предлагается настройка лица. Новые аккаунты видят предложение после регистрации. Действующий пользователь подтверждает текущий пароль; снимок не берётся из документов автоматически. Нужно отдельное согласие. Настройку можно пропустить; после отказа она доступна в «Профиль → Безопасность → Восстановление по лицу».

Нажать «Сохранить лицо через камеру», разрешить браузеру камеру, расположить лицо в овальной рамке и сделать снимок. Рамка плавно меняет подсветку; это оформление, а не проверка живого присутствия. Исходный снимок не хранится. Сохраняется зашифрованный шаблон, который можно заменить или удалить после ввода пароля.

После двух неправильных паролей за десять минут открывается сравнение нового снимка с шаблоном. При совпадении доступна форма нового пароля. Разрешение действует в рамках пятиминутной проверки и расходуется один раз. После смены нужно войти с новым паролем; прежние сессии отзываются. Документы, роли, подписки и профиль исполнителя не изменяются. Для сотрудников и заблокированных/удалённых аккаунтов способ недоступен.

По требованию владельца отсутствуют проверки фотографии, записанного видео, дипфейка и подмены потока. Фото/видео могут пройти сравнение. Это не OS Face ID и не подтверждение живого присутствия. Порог сходства 0,45 является исходным параметром реализации; точность на разных людях и устройствах ещё не откалибрована.

Модель работает на сервере JOBA в отдельном контейнере, без передачи фотографий стороннему API. Сервис не имеет публичного порта; лимит памяти 768 МБ, один CPU. Модели и зависимости закреплены, файлы моделей проверяются по SHA-256. Подробности и лицензии — `services/face/README.md`. APK не собирается.

Проверка вручную: сохранить своё лицо с согласием → выйти → дважды ошибиться в пароле → сделать новый снимок → установить пароль → войти с новым. Также проверить отказ от настройки, отмену камеры, несовпадение и удаление шаблона. Не выполнять этот сценарий с чужим аккаунтом.
