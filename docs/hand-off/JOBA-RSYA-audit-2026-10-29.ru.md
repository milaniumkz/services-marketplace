# JOBA: проверка публичного сайта для РСЯ, 29 октября 2026

Отказ «по иным причинам» не раскрывает конкретное нарушение. Ни исправления сайта, ни одобрение аккаунта AdSense не гарантируют допуска РСЯ.

## Обнаруженные проблемы и изменения

| Блок | До исправления | Изменение |
|---|---|---|
| Главная | Оболочка Flutter без содержательного HTML до запуска приложения | Открытая главная о действующем сервисе; приложение по `/app/` |
| Публичные страницы | Дизайн-прототип, кнопки с демонстрационными уведомлениями | Страницы заказчика, исполнителя, безопасности, вопросов, поддержки, стран, тарифов и документов |
| Справочник | Открытое описание не отражало базу | Категории и поиск читают действующий серверный справочник |
| Тарифы | Статические описания | Цены читаются из каталога выбранной страны; тестовая оплата обозначена явно |
| Документы | Статический HTML мог отставать от опубликованной версии | Серверный HTML читает опубликованные документы без зависимости от JavaScript |
| Контакты | Пустые реквизиты | Форма владельца «Настройки → Реквизиты и контакты»; изменения публикуются на сайте и в документах |
| Индексация | robots.txt и sitemap.xml отдавали оболочку приложения | Настоящие файлы, карта публичных страниц, неизвестные адреса возвращают 404 |
| Реклама | Нет запущенных рекламных показов | Скрипты не включены автоматически; seller-файлы сохранены в корне |

Контактные корректировки не меняют правила обработки данных, не завершают сессии и не требуют повторного согласия внутри приложения. Предыдущие тексты сохраняются в истории. Изменения самих правил по-прежнему требуют актуального согласия.

## Сверка групп требований

Основной документ для оператора Казахстана: https://yandex.kz/legal/partner/ru/ . Общая техническая справка: https://yandex.ru/support/partner/ru/yan-rules/site . Модерация: https://yandex.ru/support/partner/ru/joining/moderation . Проверка касается публичных страниц и поведения, доступного без входа; она не является юридической экспертизой всех материалов пользователей.

| Требования | Результат / границы проверки |
|---|---|
| Доступное содержимое, качество, полезный сервис, отсутствие пустой одностраничной оболочки | Добавлены содержательные взаимосвязанные страницы и действующие справочники; финальную оценку качества выполняет Яндекс |
| Запрещённые, обманные, вредоносные материалы | На проверенных публичных страницах не обнаружены; пользовательский контент требует постоянной модерации |
| Копирование, дорвеи, парковка доменов, linkfarm | Новые тексты описывают JOBA, используются реальные функции и база; нет вымышленных отзывов и статистики |
| Накрутка, принуждение к кликам, стимулированный рекламный трафик | Не используются. Нельзя просить знакомых кликать по объявлениям или покупать такой трафик |
| Размещение объявлений, перекрытие интерфейса, случайные клики, маркировка, частота обновления | Реальные рекламные блоки ещё не запущены. Проверить повторно при подключении SDK/веб-показов; не размещать рекламу вплотную к навигации и кнопкам |
| Конфиденциальность, контакты, прозрачность услуг | Документы и поддержка доступны без регистрации. Контакты редактируются владельцем; подключение рекламных SDK потребует сверить фактические передачи данных и согласия |
| Вознаграждение за просмотр | Полученный Android Rewarded ID сам по себе не означает разрешённость механики. Не связывать награду с выводимыми деньгами; проверить модель по правилам до запуска |
| Право на приложение и магазин | Для нативной монетизации ещё нужна фактическая ссылка на опубликованное приложение и проверка владельца. Нельзя подставлять вымышленную ссылку |
| Аудитория, качество посещений, вовлечённость | Невозможно подтвердить по скриншоту кабинета или коду сайта; нужны реальные данные кабинета и развитие сервиса |
| Договорные, регистрационные и платёжные данные рекламного кабинета | Проверяет владелец в кабинете; публичные контакты не заменяют оформление договора |
| Решение «по иным причинам» | Яндекс вправе отказать без раскрытия причин; конкретная причина не установлена |

Казахстанская оферта https://yandex.kz/legal/yan_service_offer/ при автоматическом получении ответила ограничением 429; её условия не объявляются проверенными. Владелец должен прочитать применяемую оферту в своём кабинете.

## Действия владельца после публикации

1. Откройте https://joba.com.kz/admin/#settings → «Реквизиты и контакты». Проверьте адрес и данные оператора. Почту и телефон можно изменить здесь в любой момент, кнопка «Сохранить и опубликовать».
2. Проверьте публичные страницы https://joba.com.kz/ , `/site/contacts.html`, `/site/pricing.html`, `/site/privacy.html`. Приложение находится на https://joba.com.kz/app/ .
3. В РСЯ: «Сайты» → JOBA → «Перейти» → «Действия» → «Отправить на модерацию». Для причины «по иным причинам» официальная справка указывает доступность повторной подачи через 30 дней после отказа. Ориентируйтесь на дату и доступную кнопку в кабинете; создание дубликатов площадки не требуется.
4. Если отказ повторится, направьте поддержке адрес сайта, ID площадки `20302217`, точный текст отказа и перечень исправлений. Не отправляйте пароли и удостоверения через публичные формы.
5. AdSense: проверьте отдельно статус сайта `joba.com.kz` в разделе «Сайты» — одобрение аккаунта не всегда означает одобрение сайта. Код ручного веб-баннера уже получен: slot `8113418919`; повторно предоставлять его не требуется. Android App ID и ID блоков уже получены; они не заменяют веб-блок.
6. Для Яндекса ещё нужны строки seller-файла из кабинета и, если нужен, Android-блок с вознаграждением. APK на этом этапе не собирается.

Не обещайте заказчику гарантированное одобрение и не используйте имитацию посещаемости или рекламных кликов.
