# Сохранение категорий услуг · 24 ноября 2026

Симптом: после заполнения «Мои услуги» сервер отвечает `VALIDATION_ERROR`, поле `category_ids`; после ухода с формы несохранённые изменения пропадают.

Причина воспроизводится на прежнем серверном коде: клиент позволяет выбрать больше десяти категорий, а валидатор сервера ограничивает список десятью. Ошибка отклоняет всю операцию сохранения. Уже сохранённый профиль при этом не удаляется.

Исправление выполнено только в API: разрешены все выбранные категории действующего справочника страны; повторяющиеся идентификаторы и предусмотренные старые идентификаторы категорий приводятся к единому виду. Неизвестные идентификаторы, пустые и некорректные списки по-прежнему отклоняются без изменения сохранённых данных. Ограничения остальных полей не ослаблены.

Контракт и маршруты запросов не изменены. Установленному приложению не нужен новый APK. Изменения вступают в силу после обновления сервера; достаточно заново открыть «Мои услуги» и сохранить форму. Данные, которые до исправления не дошли до успешного сохранения, автоматически восстановить из одной фотографии формы нельзя.

Изолированная проверка воспроизводит отказ старого кода при 12 категориях и проверяет сохранение/повторное чтение, повтор запроса без дубликата, загрузку фотографии, публикацию, повторное редактирование, совместимость идентификаторов и отказ для недопустимых категорий. Живые пользовательские профили тестами не перезаписываются. Платёжные настройки при развёртывании сохраняются.
