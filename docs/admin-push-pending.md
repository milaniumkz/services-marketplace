# Административная push-рассылка — pending implementation

Админка должна поддерживать рассылку push по сегментам страна/язык/роль, назначение времени отправки и отмену запланированной рассылки. Сегментация использует согласованные country/language/role значения продукта; подробные права администратора, статусы доставки и правила жизненного цикла задаёт полное ТЗ.

Рассылка содержит безопасную ссылку на поддерживаемый экран приложения. При открытии приложение и backend проверяют текущую авторизацию и entitlement: push-ссылка не обходит доступ и не выдаёт права. Недопустим произвольный исполняемый URL; конкретный allowlist маршрутов определит ТЗ.

Push-провайдеры, токены устройств, endpoint рассылки, scheduler и интерфейс кампаний пока не реализованы. Никакие реальные уведомления не отправляются и персональные данные не собираются. Реализация ожидает полный документ в docs/spec.
