# Прямой переход к оплате БЦК

JOBA не запрашивает адрес держателя карты. Техническая POST-форма автоматически открывает банковскую страницу без дополнительной кнопки или поясняющего экрана, в том числе для небольших сумм. Если настоящий адрес уже известен, он может быть передан; иначе поле не заполняется. Адрес ИП и выдуманные значения не используются.

18.11.2026 выполнен реальный запрос к sandbox с публичными тестовыми параметрами банка: без billAddrLine1 получена банковская форма с полем CARD, HTTP200. Карточные данные не вводились, списание не выполнялось. Это проверка открытия формы, а не всей 3DS-оплаты. Документация БЦК содержит требование billAddrLine1 (CHANGELOG 26.05.2026); успешная полная боевая операция без него не подтверждена. При отказе 3DS требуется согласование с банком, а не подстановка чужого адреса.

Новые BCC-платежи отменяются сразу, если форма ещё не была выдана браузеру. Открытие формы и отмена сериализованы блокировкой. После открытия результат подтверждается банком: при незавершённой операции показывается ожидание отмены, повторное списание не предлагается. Существующий незавершённый платёж можно продолжить по той же ссылке; после окончательной отмены, отказа или истечения срока доступно оформление новой попытки.

Старые платежи без признака отслеживания открытия формы не считаются безопасно отменёнными локально. Боевые списания и возвраты в проверках не выполнялись.
