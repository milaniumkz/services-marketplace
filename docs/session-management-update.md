# S15.sessions и настройки: независимый отзыв сессий

19 октября 2026 список устройств переведён на отдельный компонент по структуре S15.sessions: заголовок, пояснение, карточки, отметка текущего устройства, отдельный отзыв удалённой сессии и действие для всех остальных устройств. Текущая сессия показывается первой. Названия ОС, модели, приблизительный город и последняя активность не выдумываются: API пока отдаёт только семейство, текущий статус и срок refresh-токена. Вместо демонстрационных метаданных показан честный запасной текст; срок подписан как срок сессии, а не активность.

До изменения массовая кнопка вела на выход со всех устройств. Добавлены отдельный `POST /auth/logout-others`, подтверждение текущим паролем и отдельный маршрут формы. Сервер отзывает access/refresh других семейств того же пользователя/страны, сохраняет текущее и пишет security event. При одном текущем устройстве массовая кнопка скрыта. Общий выход остаётся отдельной операцией.

Поздние ответы отдельного и массового отзыва не выполняют навигацию и не очищают сессию другого аккаунта. Подтверждение отдельного отзыва получает ключ по семейству, чтобы состояние запроса не переносилось на другой выбранный сеанс.

Дополнительно исправлена согласованность S35.notifications: API отдаёт `version` из той же записи, что и значения настроек; PATCH использует эту версию, а не результат отдельного GET профиля.
