# Бесплатная мобильная версия JOBA

Решение владельца от 02.11.2026: Android/iOS выпускаются бесплатно, без подписок, покупок, реферальных платных наград и платного продвижения. Оплата работы специалиста согласуется сторонами самостоятельно.

Сборки магазинов используют `--dart-define=JOBA_FREE_MOBILE=true`. Flutter Web игнорирует этот флаг. Покупки и ссылки на платные экраны скрыты, уведомления/старые переходы на эти экраны ведут к профилю. Поддержка, приватность, удаление аккаунта и обращения по ранее совершённым платежам остаются доступны.

API включает бесплатные основные операции только при `JOBA_MOBILE_FREE_ACCESS=1` и публичном канале `X-Joba-Client: mobile-free-v1`. Это общедоступный канал обслуживания, а не секрет, аттестация устройства или доказательство происхождения клиента. Любой аутентифицированный пользователь может пользоваться бесплатным каналом. Проверки личности, роли, статуса аккаунта, согласий, владельца объекта, модерации и служебных полномочий сохраняются. Платные преимущества, лимитированные рекламные награды и продвижение не выдаются; платные grants не создаются и не расходуются. Запросы обычного web-канала сохраняют прежнюю ценовую политику.

Изоляция запросов обеспечивается AsyncLocalStorage, а не общим mutable состоянием. Тест `mobile-free-access.test.cjs` проверяет параллельные mobile/web запросы, отказ до проверки личности, ограниченные аккаунты, отсутствие служебных полномочий и сохранение платной web-политики.

Workflow `store-mobile-release.yml` развёртывает только API: проверяет host key, делает закрытую резервную копию PostgreSQL, собирает образ, перезапускает API и проверяет `/api/v1/public/mobile-release`. В случае ошибки до завершения выполняет откат образа/compose. Существующие web-артефакты сохраняются. Текущий API commit хранится на сервере в `/etc/joba/mobile-api-release` отдельно от web-релиза.

По отдельному разрешению владельца создаётся демонстрационный пользователь для Apple/Google. Он явно помечен `store_review_demo`, не представляет реального идентифицированного человека, не получает служебных полномочий или фиктивных платежей. Назначение и авторизация записываются в audit. Документы личности не подделываются и не передаются проверяющим. Аккаунт использует те же функции приложения; его предварительное разрешение доступа необходимо прямо указать в примечаниях ревью. Пароль сохраняется только в закрытом volume сервера, для владельца возвращается RSA-OAEP-зашифрованный envelope. Повторный запуск не меняет пароль и не перезаписывает чужой аккаунт.
