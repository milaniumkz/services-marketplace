# Мобильная версия JOBA: платные функции восстановлены

Решение владельца от 04.11.2026 заменяет бесплатный выпуск от 02.11.2026. Новые сборки используют `--dart-define=JOBA_FREE_MOBILE=false`: доступны «Мой доступ», управление подпиской, смена тарифа, продление, Топ-100, реклама за подписку, приглашения и бонусы. Код и тарифы общие с веб-версией. Скрипт `scripts/build-store-android.py` уже использует платный режим. Для iOS также нельзя передавать старый флаг `JOBA_FREE_MOBILE=true`.

Публичный API-канал `mobile-free-v1` временно сохраняется исключительно для совместимости с уже установленной старой бесплатной сборкой. Новые сборки этот заголовок не отправляют и используют обычные проверки подписки. Отключать старый канал следует после распространения обновления, иначе старые приложения, в которых нет кнопки оплаты, потеряют доступ без возможности приобрести подписку.

Реклама Android использует нативный SDK Яндекса: баннер `R-M-20254161-1`, Rewarded `R-M-20254161-3`. Идентификаторы и количество просмотров редактируются в админке. Для iOS нужны отдельные одобренные блоки iOS; Android-блоки туда не подставляются. Подписка заказчика, Стандарт и Топ-100 зарабатываются раздельно, по 30 дней. Незавершённые ролики не засчитываются. Завершение сообщается callback SDK и учитывается тем же серверным механизмом прогресса, что в веб-версии.

Предварительная ручная проверка остаётся только у документов. Заказы, услуги и портфолио публикуются без ожидания администратора после заполнения обязательных данных. Публичная видимость исполнителя по-прежнему требует одобренного документа. Жалобы и последующее ограничение контента доступны.

Обычное развёртывание API не создаёт и не восстанавливает удалённый демонстрационный аккаунт магазина. Его создание — отдельная явно включаемая операция `provision_store_review`. Это не влияет на существующих пользователей.
