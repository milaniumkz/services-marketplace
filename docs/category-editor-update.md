# Категории: дерево, переводы и дополнительные поля

Часть блока 5: категория редактируется отдельными полями вместо JSON. Доступ требует content (или administrator), MFA и своей страны. На основном экране показаны опубликованное дерево и выбранная категория; «Новая категория» открывает пустой черновик.

Есть родитель, иконка из разрешённого набора, обязательные переводы страны (ru/kk для KZ, ru/ky для KG, ru для RU, ru/be для BY), стабильный ID и причина изменения. Схема заказа допускает до 50 полей: текст/варианты, целое, число, да/нет, обязательность, допустимые длины и числовые границы. Строковые варианты задаются построчно. Произвольный regex и опасные ключи не допускаются.

Собственный черновик обновляется с expected_version; опубликованная или чужая запись сохраняется новой версией. Перед независимой публикацией проверяются переводы, схема, опубликованный родитель той же страны, глубина и отсутствие циклов. Одновременные изменения дерева сериализуются по стране через PostgreSQL advisory lock. Черновик, созданный до другой публикации той же категории, не может перезаписать свежую версию без создания нового черновика от актуального каталога.

Публичный ID категории сохраняется при смене версии. API каталога дополнительно возвращает version_id, parent_id и icon. Устойчивый ID используется в новых заказах, профилях и портфолио. Старые записи не удаляются и не переименовываются массово. Старый legacy_id справочной категории сохраняется в новых версиях и откатах.

При создании заказа сохраняются публичное название, переводы и схема категории. Изменение каталога не переписывает этот снимок. Существующий заказ можно редактировать с его прежними полями после изменения/архивирования категории. Новые заказы в архивной категории не публикуются. Копия заказа получает актуальную схему; перед публикацией должна заполнить её обязательные поля. Архивирование категории с опубликованными дочерними узлами блокируется до переноса или архивирования детей. Исторические записи остаются доступны по прежним связям.

Визуальная приёмка A08, остальные формы блока 5, массовая миграция исторических данных и эксплуатационные измерения остаются открыты. Интерфейс не имитирует готовность этих работ. Изменения этого этапа не развёрнуты на сервере.
