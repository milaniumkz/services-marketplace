# Управление аккаунтами

Админка: https://joba.com.kz/admin/ → «Пользователи» → открыть аккаунт → «Обзор» → «Управление аккаунтом».

- **Заблокировать (бан)** — закрывает вход, завершает все сессии и скрывает материалы из публичного поиска. Сохраняет данные аккаунта.
- **Разблокировать** — возвращает возможность входа. Отдельные действующие ограничения модерации сохраняются до решения по ним.
- **Удалить аккаунт** — нажмите кнопку. Аккаунт сразу получает статус «Удалён», вход закрывается, сессии отзываются. Очистка связанных записей выполняется в фоне.

Все три действия выполняются отдельными кнопками, без причин, ввода ID и дополнительных диалогов. Просмотр телефона, документов и событий безопасности также не требует заполнения основания. Действия автоматически записываются в журнал. При конфликте ревизии обновите карточку.

Владелец может выдать каждую из трёх функций отдельно в динамической роли, блок «Аккаунты». Эти действия предназначены для пользовательских аккаунтов; учётные записи сотрудников управляются в разделе сотрудников.
