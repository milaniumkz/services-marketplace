# Новый логотип JOBA

Изображение владельца используется как источник логотипа, иконок и стартовых экранов. Композиция и надпись Joba сохранены. После улучшения чёткости подготовлены квадратные размеры без обрезки. Канонический PNG: `branding/joba-source.png` (1254 × 1254); увеличенный мастер: `branding/joba-master-4096.png` (4096 × 4096). Мастер предназначен для передачи и не загружается при открытии приложения.

`node scripts/generate-mobile-icons.cjs` воспроизводит 83 растровых варианта. `branding/manifest.json` хранит размеры, назначение и SHA-256 каждого файла.

- Flutter: PNG 512 × 512 для отображения 140 × 140, без загрузки тяжёлого мастера.
- Web, админка, публичные страницы и прототип: основной логотип 512 px, компактный 192 px, favicon 48 px; референс редактора бренда — 1024 px, в допустимом лимите 5 MB.
- Android: mdpi–xxxhdpi, обычная, круглая и адаптивная иконки, а также стартовый экран. Полный рисунок помещён внутрь безопасной зоны адаптивной маски, наружные поля не заменяют фон самого рисунка.
- iPhone/iPad/App Store: все существующие слоты AppIcon, включая непрозрачный PNG 1024 px; стартовые изображения 1x/2x/3x.
- PWA: обычные и maskable-иконки 192/512 px, отдельный Apple touch icon 180 px. У maskable добавлены технические поля, чтобы круглая маска не обрезала изображение.
- Push Web: новый значок 192 px применяется и в серверном FCM-пакете, и при системном показе в открытой вкладке.

Новые имена файлов позволяют браузеру загрузить обновлённый логотип. Старые публичные URL JPEG и Icon-192/512 оставлены с обновлённым содержимым для совместимости. Генератор пакетов в админке использует цвет фона исходника и безопасную область полного рисунка; процедура независимого утверждения версии сохранена.

Проверено: размеры всех 83 файлов, непрозрачность iOS, наличие ресурсов PWA, сборки админки и публичного сайта, существующая проверка серверного генератора иконок. Анализ Dart без замечаний. APK по указанию владельца не собирается: установленный APK получит новые ресурсы после будущей сборки и установки. Уже установленная PWA может обновить домашнюю иконку по расписанию браузера; новые установки используют новую иконку.
