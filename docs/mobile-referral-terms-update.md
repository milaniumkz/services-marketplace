# Условия реферальных бонусов в мобильном приложении

16.10.2026. Экран правил отображает из API порог, событие, набор временных прав, длительность и окно ввода кода после регистрации, если оно задано. Карточка выданной награды использует её собственный `policy_snapshot`, а не текущую кампанию, и показывает конечную дату активации в локальном времени устройства.

Кнопка активации доступна только для `available` с корректной будущей датой `expires_at`; точная граница и уже погашенная награда недоступны. Сервер остаётся окончательным источником решения о погашении. Это не вводит подписку для заказчика.

Добавлены переводы новых строк на казахский, белорусский и сербский (существующая языковая опция, независимо от замены страны на Кыргызстан). Полный кыргызский интерфейс этим изменением не добавлен.

Проверка 1:1 экранов S37/S37.rules/S37.redeem остаётся открытой. Изменение не развёрнуто на рабочий сервер.

Проверки: анализ Flutter — 0 замечаний; полный мобильный набор — 84 успешно, 2 пропущены; после уточнения отображения неизвестного события повторно прошли 3 целевых теста (условия, границы активации, навигация). Изолированная проверка Flutter ↔ HTTP API — 1 успешно. Серверный код не менялся.

Визуальный набор снят повторно (115 кадров). Фикстура S37 не содержит наград и срока ввода кода; эти ветки проверены отдельными widget-тестами, а снимки не выдаются за их визуальную приёмку. Исходные иллюстрации перед запуском подготовлены штатным скриптом.
