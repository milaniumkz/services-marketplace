# Структурированные настройки рейтинга

Вместо общего JSON-редактора на `#ranking` подключена отдельная форма: название, страна, окно голосования (1–3650 суток), вес отрицательной реакции (0–100, дробный), срок затухания (1–3650 суток), фиксированная формула log_likes_decay_v1. Переход доступен из «Топ и продвижение» и вкладок продвижения.

API нормализует параметры и не сохраняет произвольные scope/role. Собственный черновик редактируется PATCH с expected_version; для чужой или опубликованной версии создаётся новый черновик. Публикация требует другого сотрудника; она заменяет предыдущую действующую конфигурацию того же региона. Доступны проверка, предпросмотр параметров, остановка и черновик отката. Изменённую форму нужно сохранить до выполнения команд; ошибка не стирает значения.

Формула соответствует действующему серверному органическому ранжированию: max(0, ln(1+likes) − weight×ln(1+dislikes))×exp(−age/decay). Предпросмотр не моделирует состав/позиции карточек и не подставляет постановочную выдачу: возвращаются версия, регион и счётчики из API. Платные размещения учитываются отдельно. После остановки версии используются действующие региональные настройки по умолчанию, голоса сохраняются.

Тест API проверяет границы, нормализацию, чтение, чужой/устаревший PATCH, независимую публикацию и параметры фактического `/top-listings` до/после остановки. Браузерный сценарий проверяет переход из Топа, отсутствие JSON, сохранение дробного веса, редактирование версии, блокировку команд при несохранённых изменениях, предпросмотр и запрет самостоятельной публикации.

Форма рейтинга — дополнительный рабочий раздел; отдельный исходный кадр для него не обнаружен в реестре 187. Она не объявляется визуально принятой. Вся приёмка макетов остаётся открытой. Изменение не развёрнуто на рабочий сервер.
