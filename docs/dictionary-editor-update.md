# Структурированный словарь модерации

Форма `#dictionary` (также `#dictionaries`) заменяет JSON отдельными правилами. Для каждого правила доступны слово/фраза, тип совпадения и области применения: имя пользователя, заказ, отклик, профиль, портфолио, сообщение и отзыв. Правила добавляются и удаляются; исключения вводятся по одному в строке. ID существующих правил сохраняются. Страна берётся из сессии сотрудника.

Добавлены GET/PATCH `/admin/moderation-dictionaries/{id}`. PATCH допускается только для собственного черновика с ожидаемой версией и причиной. Валидация проверяет пустые значения, длину, тип, поверхности, уникальность ID, формат исключений и отсутствие regex; посторонние поля не сохраняются. Ограничение — 1000 правил и 1000 исключений. Пустой словарь допустим, он ничего не блокирует.

Проверка и предпросмотр требуют актуальной версии, причины и записываются в аудит. Публиковать можно только черновик, причём другим сотрудником с правом moderator_manager и MFA. Повторная публикация опубликованного/остановленного словаря запрещена. Пробная проверка текста остаётся отдельным экраном, не создаёт дела и не меняет контент. Несохранённые изменения блокируют команды формы; ошибки сохраняют поля.

Опубликованные словари региона применяются совместно. Копия не выключает предыдущий словарь: для этого есть явная остановка. Текущая модель направляет совпавший материал в карантин и создаёт дело для ручного решения. Публикация и остановка не перепроверяют старый контент и не закрывают прежние дела.

Проверено: сборки всех рабочих пространств; 97 тестов API без ошибок, включая новый сценарий редактирования, прав, версий, исключений, пробного запуска, публикации, фактической модерации заказа и остановки. Браузерный прогон через настоящий HTTP API: создание, добавление/удаление правила, редактирование, блокировка несохранённой версии, предпросмотр и отказ автору в публикации. База изолирована от рабочего сервера.

A18 остаётся в визуальной приёмке. Форма ещё не совпадает с таблицей макета 1:1; языковая область и отдельные действия правил требуют дальнейшей сверки с ТЗ.
