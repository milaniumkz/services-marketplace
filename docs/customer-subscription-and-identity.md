# Подписки и проверка личности — 27 октября 2026

Новая инструкция владельца заменяет прежнюю модель «заказчик бесплатно».

- Заказчик: 500 ₸ на 30 дней в Казахстане. Доступ к анкетам исполнителей, включая портфолио, и размещение заказов.
- Исполнитель: Стандарт и Премиум на 30 дней; Премиум даёт приоритет услуг в Топ-100. Базовые значения кода — 1000/1500 ₸. На рабочем сервере сохранены заданные владельцем цены 500/700 ₸; развёртывание их не перезаписывает.
- Цены редактируются в админке → Монетизация → Каталог цен. Для заказчика в других странах цену в местной валюте нужно задать перед продажей; конвертация 500 ₸ не выдумывается.
- Подписки разделены по ролям. Подписка заказчика не открывает поиск работы или публикацию услуг исполнителя. Общение и завершение существующих заказов сохраняются после окончания подписки.

## Проверка личности

Для обеих ролей: «Мой профиль» → «Проверка личности». Прочитайте согласие, загрузите две стороны удостоверения и отдельное селфи, затем отправьте на проверку. Пропуск фотографии или файлы из чужой заявки отклоняются сервером. Разрешены JPEG/PNG, файлы проходят существующую проверку загрузок.

Администратор с правами проверки открывает заявку, указывает служебную причину и видит три подписанные фотографии. Утверждение требует актуальной ревизии и срока действия проверки. При отказе укажите причину: пользователь сможет отправить фотографии заново.

После одобрения сервер создаёт отдельный квадратный аватар 512×512 из третьего файла — селфи, удаляя EXIF. Исходное селфи и обе стороны удостоверения остаются в закрытом зашифрованном хранилище; идентификаторы документов не выдаются посетителям профиля. Проверка общая для аккаунта, поэтому смена роли не требует повторной загрузки. Существующие одобренные проверки не аннулируются автоматически; новые заявки требуют три фотографии.

Правила и согласие публикуются идемпотентным `scripts/publish-role-access.cjs` при развёртывании. Последующие правки владельца не перезаписываются на каждом деплое. Коммерческая информация Казахстана обновляется с сохранением прежних версий и реквизитов.

## Тестирование

Веб-приложение: https://joba.com.kz/ ; админка: https://joba.com.kz/admin/ . В эту итерацию APK не выпускается; установленное приложение получит новые клиентские экраны только в следующей сборке.

Платёжный провайдер на момент проверки не подключён. Каталог показывает реальные сохранённые тарифы, но неподтверждённое списание не активирует доступ. Положительные сценарии подтверждённой оплаты, истечения и разделения прав проверяются через изолированный API с sandbox-доказательствами. Это не банковская операция на рабочем сервере. Ручные компенсации в админке по-прежнему требуют второго уполномоченного сотрудника.
