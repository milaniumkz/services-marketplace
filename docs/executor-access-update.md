# S05: выбор доступа исполнителя

19 октября 2026 исправлена маршрутизация: `access` ошибочно попадал в ветку `refunds`. Теперь исполнитель видит выбор доступа, заказчик — бесплатные возможности; платежи и возвраты открываются своим маршрутом.

Неподключённая рекламная сеть обозначена недоступной; карточка открывает условия без выдачи награды.
