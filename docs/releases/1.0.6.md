# JOBA 1.0.6 (8)

- На экране настройки восстановления по лицу действие «Продолжить без настройки лица» закреплено отдельно от прокручиваемого текста. Минимальная высота кнопки 48 dp; проверены экран 320×568 и масштаб текста 180%.
- Для обеих сторон удостоверения в Android снова доступны галерея и камера. Селфи остаётся только через камеру; веб-загрузка удостоверения сохраняет выбор файла.
- Селфи в Android снимается встроенным модулем камеры с явным выбором фронтального объектива. Он используется и для селфи проверки документов, и для кадров восстановления по лицу. При отсутствии фронтальной камеры показывается ошибка, задняя камера вместо неё не запускается.
- Запись звука отключена; разрешение RECORD_AUDIO исключено из Android-манифеста. Временный файл снимка удаляется после чтения. Камера освобождается при уходе в фон и заново открывается с фронтальным объективом после возврата.
- Исправлена проверка доступа при приглашении исполнителя: оплачивающий заказчик не должен покупать доступ из-за отсутствия подписки у получателя. Получение приглашения бесплатно; собственный доступ исполнителя проверяется при принятии. Истёкшая подписка отправителя не перенаправляет получателя на оплату за другого пользователя.

Проверены 30 целевых Flutter-тестов (экран, камера, галерея, проверка документов, сохранение состояния и оплата), анализатор и 11 серверных сценариев приглашений и подписок. Серверное исправление приглашений опубликовано из `bfa4cc1044fc581965bb6eb08c770bfd380d24db`.

Работа физической камеры на настоящем телефоне в этой среде не проверялась. Использованы тестовый драйвер камеры и сборочные проверки Android; тестовый APK предназначен для проверки пользователем перед публикацией в магазине.
