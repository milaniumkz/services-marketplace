# JOBA 1.0.7 (9), 05.11.2026

Основа: актуальная `feat/joba-implementation` / `Project/store-publication`, коммит eac4e4f. Включены исправления фронтальной камеры (освобождение устройства между кадрами), доступности действий восстановления по лицу, выбора документов, сохранения состояния при возврате из камеры, поиска рядом и доставка отчётов о сбоях. Общая редакция также содержит VTB checkout и нативную рекламу.

Google Play собирается с `JOBA_FREE_MOBILE=true`, как ранее согласовано владельцем. Цифровые покупки и банковские маршруты скрыты/заблокированы. RuStore собирается с `JOBA_FREE_MOBILE=false`, с актуальными платными функциями. `scripts/build-store-android.py` принимает переменные `JOBA_FREE_MOBILE` (по умолчанию true) и `JOBA_ANDROID_FORMAT` (appbundle или apk).

Подготовлены `release/store/JOBA-1.0.7-9-google-play.aab`, `JOBA-1.0.7-9-rustore.aab`, `JOBA-1.0.7-9-rustore.apk`. Подпись AAB проверена jarsigner, подпись APK — apksigner. Проверены zipalign 16 KiB и все 12 arm64/x86_64 ELF-библиотек. Анализатор без замечаний. Пройдено 13 тестов камеры/очереди сбоев/баннера; отдельные два теста профиля и возврата из камеры прошли как в стандартной, так и в бесплатной конфигурации. Первоначальный тест с ожиданием платного меню был запущен с бесплатным флагом: ожидание уточнено для двух конфигураций, обе проверены.

Декларации Google обновлены: точная геопозиция для поиска рядом (необязательно, временная обработка), отчёты об ошибках и диагностика, рекламный идентификатор для нового Yandex SDK и передача идентификаторов для рекламы. Статус продавца приложения наследует подтверждённый статус аккаунта; добавлена ссылка на условия JOBA. Прежний демонстрационный аккаунт оказался удалён. По отдельному подтверждению владельца 05.11 создан новый аккаунт, старый не восстанавливался; вход нового проверен, Google получил актуальные данные.

Предупреждения Google: увеличение размера APK и исключение 127 моделей устройств относительно сборки 2. Минимальный Android API 24, target 36. Работа физической камеры на телефоне этим релизным прогоном не проверялась.

Закрытый комплект ключа владельца — вне Git, `~/.joba-publication/rustore/`. Он содержит JKS, параметры/пароли и открытый PEM-сертификат. Это не PEPK ZIP для загрузки подписи: такой ZIP требует уникального encryptionkey из консоли RuStore, который владелец предоставит отдельно. APK можно загрузить без PEPK. Локальный ключ не является закрытым Google App Signing key; совместимость обновлений установок из разных магазинов по подписи не заявляется.

Контрольные суммы и фактический статус отправки: `release/store/JOBA-1.0.7-9-verification.json`.
