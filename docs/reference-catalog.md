# Справочники населённых пунктов и услуг

Импорт подготовлен по прямому поручению владельца от 20.10.2026. Это справочные данные, без искусственных пользователей, заказов и покупок.

- Казахстан: 351 населённый пункт, включая Алатау.
- Кыргызстан: 107 населённых пунктов; Манас доступен и по прежнему названию Джалал-Абад.
- Россия: 5143 населённых пункта.
- Беларусь: 314 населённых пунктов.
- Каждая страна: 31 раздел, 147 подкатегорий, 755 специализаций — 933 узла дерева.

География: GeoNames cities500 плюс бывший Жетыген (ныне Алатау), альтернативные названия и административные регионы. Отсеяны кварталы, исторические и заброшенные поселения. Включены города и другие населённые пункты; это не официальный исчерпывающий реестр городских статусов. Основная выдача на русском/кириллице при наличии соответствующего названия в источнике. Иные достоверные варианты сохранены без выдуманного перевода. Население используется только для сортировки, а не как актуальная перепись.

Лицензия: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . Атрибуция: GeoNames geographical database, https://www.geonames.org/ . Источники, SHA-256 выгрузок и поправки: `services/api/reference/cities-source.json`. Публичная атрибуция: `/site/data-sources.html`; сведения об источнике также возвращаются API городов.

Каталог услуг авторский, трёхуровневый, русскоязычный. Имеющиеся переводы пяти прежних разделов сохраняются. Новым узлам не назначаются вымышленные переводы: другие языки используют русскую подпись до заполнения перевода.

Данные хранятся в PostgreSQL как записи city/category. API `/geo/cities` выдаёт полный справочник текущей страны, поддерживает `q` и старые названия; категории доступны через `/catalog/categories` и редактируются существующим редактором админки. Выбор родительской категории в поиске включает все действующие дочерние специализации. CitySelector строит только видимые строки.

`importReferenceDataset` выполняет проверку, транзакцию, блокировку и пакетные вставки без перезаписи существующих записей. Повтор того же набора определяется по хешу и ничего не меняет. Сохраняются старые ID базовых городов и пяти категорий, существующие заказы, профили и пользовательские изменения. Импорт добавлен к deploy после резервного копирования и запуска новой версии API; аудит содержит счётчики по странам. Архивированные родительские категории не включаются обратно автоматически.

Генерация: `python3 scripts/reference/build-categories.py`; `python3 scripts/reference/build-cities.py` читает сохранённые публичные выгрузки из `/workspace/joba-reference-sources`. Для сборки и работы сервера загрузка GeoNames не требуется — проверенные JSON находятся в репозитории.

## Выбор в приложении

Город: сначала показываются области/регионы из поля `region` серверных записей, затем населённые пункты выбранного региона. Поиск сверху работает сразу по всему справочнику текущей страны: название, регион и альтернативные/прежние названия. Записи без региона доступны в отдельной группе. Никакие названия регионов не зашиты в UI.

Категория: сначала корневые разделы, после нажатия — дочерние подкатегории и специализации. Переход назад поднимает на один уровень. Можно выбрать текущий раздел целиком либо конкретную специализацию. Поиск работает по всему дереву и показывает путь родительских категорий. Отмена не изменяет форму; окончательный выбор подтверждается кнопкой.

Общий компонент используется выбором города в профиле и на главной, формой заказа, фильтрами, Топом, основными и дополнительными категориями исполнителя и категорией портфолио. Фильтры позволяют сбросить ограничение через «Все города» / «Все категории». Все списки строятся лениво, только для видимых строк.

Это изменение интерфейса требует нового APK для Android. Последующие изменения содержимого справочника приходят через API без пересборки APK.
