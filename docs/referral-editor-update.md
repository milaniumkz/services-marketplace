# Форма реферальной кампании A20

16.10.2026. Вместо общего JSON-редактора подключена отдельная форма к реальному API: название, страна, подтверждаемое событие, порог приглашений, бюджет в единицах наград, срок и набор временных прав исполнителя.

Сохранение своего черновика использует PATCH с expected_version; чужая или опубликованная версия сохраняется новым черновиком. Проверка и предпросмотр относятся к сохранённой версии, несохранённые изменения блокируют команды. Публикацию подтверждает другой сотрудник. Доступны остановка и создание черновика отката через существующий жизненный цикл конфигурации. Метрики атрибуций, квалификаций, выданных/погашенных наград и занятого бюджета считаются по региональным записям выбранной кампании. Список версий поддерживает курсор.

API отклоняет дробный/небезопасный бюджет, недопустимые события, пустые/повторяющиеся/произвольные capabilities, денежные и многоуровневые награды. Максимум бюджета — миллион наград, длительности — 366 суток. В регионе публикуется одна действующая реферальная кампания, чтобы выбор кампании при атрибуции оставался однозначным.

Не завершены: окно атрибуции, правила освобождения незавершённого резерва, миграция исторических обязательств, скидки/предложения платёжного провайдера. Экран явно показывает ограничения доступной механики. Подписка заказчику не вводится.

Визуальная приёмка A20 и A20.preview открыта: общий каркас, типографика, размеры и представление предпросмотра требуют дальнейшей сверки. Наличие формы и снимка не означает совпадение 1:1. Изменение не развёрнуто на рабочий сервер.

Проверки: сборка всех workspace; 91 тест API успешно, 0 ошибок и пропусков. Браузерный сценарий через реальный изолированный HTTP API проверяет форму без JSON, создание, PATCH версии, блокировку команд при несохранённых изменениях, предпросмотр и отказ в самостоятельной публикации.

## Отдельный предпросмотр A20.preview

Следующий блок: предпросмотр больше не дублирует редактор. По выбранному ID показаны карточка условий для участника, порог, временные права, срок, событие, региональный бюджет и независимое подтверждение публикации. Кнопка проверки использует версию и аудируемое основание; результат API не выдаёт привилегий. Возврат сохраняет выбор кампании. Без выбранной/действующей кампании предлагается реальный список версий с курсором, без постановочных условий.

Правый блок контроля обещаний A20 приведён к компактным строкам макета, добавлен переход в предпросмотр именно сохранённой версии. Карточки и поля получили отдельные отступы. Прогресс произвольного участника не подставляется: в административном предпросмотре участник не выбран. Денежный DEMO offer из макета не заменяет фактическую временную привилегию.

Визуальная приёмка остаётся открытой: общий каркас, типографика, несовпадение реализуемого предложения с демонстрационной скидкой, сетка полей редактора. Массовая проверка API не повторялась: серверный код этим блоком не менялся.

Итоговая проверка этого блока: сборка админки успешна; браузерный набор прошёл, 72 снимка без ошибок маршрутов. Добавлены проверки перехода в отдельный предпросмотр, аудируемой проверки версии без наград, возврата и выбора кампании из списка.
