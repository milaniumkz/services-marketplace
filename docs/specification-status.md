# Статус ТЗ

Полное ТЗ готовит отдельный автор. Этот документ не заменяет его. После получения требуется согласовать состояния заказов и откликов, разрешения ролей, правила репутации, модерации и апелляций, сроки хранения, модели данных, ограничения доступа, уведомления, поиск и монетизацию по странам. Реализация начинается в отдельной feature branch с draft PR.
