# Статус ТЗ

Полное ТЗ готовит отдельный автор. Этот документ не заменяет его. После получения требуется согласовать состояния заказов и откликов, разрешения ролей, правила репутации, модерации и апелляций, сроки хранения, модели данных, ограничения доступа, уведомления, поиск и монетизацию по странам. Реализация начинается в отдельной feature branch с draft PR.

Полный документ проходит финальное оформление; файлы для `docs/spec` ещё не получены. Последние уточнения до его передачи: [баннеры и промоцена подписки](monetization-demo.md), [push-рассылки из админки](admin-push-pending.md). Все эти пункты имеют статус pending implementation.

Последнее уточнение [авторизации](auth-pending.md) заменяет обязательный OAuth: телефон + пароль без SMS, сохранённая сессия и локальная разблокировка. Recovery pending decision.
