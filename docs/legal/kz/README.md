# Первоначальные документы JOBA для Казахстана

Владелец поручил подготовить и опубликовать эти тексты 15.10.2026, оставив реквизиты пустыми для последующего заполнения в админке. Это первоначальные редакции, а не юридическое заключение о соответствии конкретного бизнеса всем требованиям.

Нормативные ориентиры для проверки актуальных редакций:

- [Закон «О персональных данных и их защите» № 94-V](https://adilet.zan.kz/rus/docs/Z1300000094).
- [Закон «О защите прав потребителей» № 274-IV](https://adilet.zan.kz/rus/docs/Z100000274_).
- [Закон «О регулировании торговой деятельности» № 544-II](https://adilet.zan.kz/rus/docs/Z040000544_).

Актуальные редакции актов и применимость к модели JOBA требуют проверки специалистом; внешняя правовая проверка при подготовке не выполнена. Не заполнены реквизиты и конкретный график хранения; не подтверждены физическая локализация инфраструктуры и условия будущих провайдеров. Подготовка политики сама по себе не реализует недостающие технические процедуры удаления и хранения.

Админка → «Правовые документы» → «Редактировать новой версией»: заполнить реквизиты в тексте, внести уточнения, сохранить черновик. Опубликованные версии не переписываются. Обычная публикация требует другого уполномоченного сотрудника. Первоначальный offline-импорт выполняет отдельное явное поручение владельца и записывает его в audit без имитации второй подписи. Повторный импорт сохраняет существующие документы.
