# Первоначальные документы JOBA для Казахстана

Владелец поручил подготовить и опубликовать эти тексты 15.10.2026, оставив реквизиты пустыми для последующего заполнения в админке. Это первоначальные редакции, а не юридическое заключение о соответствии конкретного бизнеса всем требованиям.

Нормативные ориентиры для проверки актуальных редакций:

- [Закон «О персональных данных и их защите» № 94-V](https://adilet.zan.kz/rus/docs/Z1300000094).
- [Закон «О защите прав потребителей» № 274-IV](https://adilet.zan.kz/rus/docs/Z100000274_).
- [Закон «О регулировании торговой деятельности» № 544-II](https://adilet.zan.kz/rus/docs/Z040000544_).

Актуальные редакции актов и применимость к модели JOBA требуют проверки специалистом; внешняя правовая проверка при подготовке не выполнена. Не заполнены реквизиты и конкретный график хранения; не подтверждены физическая локализация инфраструктуры и условия будущих провайдеров. Подготовка политики сама по себе не реализует недостающие технические процедуры удаления и хранения.

Админка → «Правовые документы» → «Редактировать новой версией»: заполнить реквизиты в тексте, внести уточнения, сохранить черновик. Опубликованные версии не переписываются. Обычная публикация требует другого уполномоченного сотрудника. Первоначальный offline-импорт выполняет отдельное явное поручение владельца и записывает его в audit без имитации второй подписи. Повторный импорт сохраняет существующие документы.

## Информация для подключения приёма платежей (16.10.2026)

Добавлены исходники `payments.ru.txt`, `refunds.ru.txt`, `public_offer.ru.txt`, `contacts.ru.txt`: предмет оплаты, цена/валюта, подтверждение и предоставление электронной услуги, отдельное согласие на автоплатёж, основания/подача/рассмотрение возврата и реквизиты. Подписка заказчика не продаётся; добровольное продвижение заказа — отдельная необязательная услуга действующей модели.

На публичном сайте: W03 (конфиденциальность), W06 (оплата), W07 (возврат), W08 (оферта), W09 (контакты); ссылки есть в футере всех публичных страниц. `scripts/build-public-legal.cjs` генерирует читаемый без JavaScript текст из этих исходников. На Казахстан/русский доступна редакция сайта, а опубликованная версия API имеет приоритет. При недоступности API показана явно обозначенная редакция сайта. Для другой страны/языка казахстанский текст не подставляется.

В админке «Правовые документы» добавлены соответствующие типы. Исправление создаёт новую версию, публикацию подтверждает другой сотрудник. При следующем развёртывании `publish-kz-commerce-legal.cjs` импортирует отсутствующие первоначальные документы по явному поручению владельца; повтор не перезаписывает документы/черновики администратора. Реквизиты оставлены пустыми, как ранее поручено владельцем.

До передачи банку нужно заполнить реальные реквизиты/контакты и подтвердить фактические тарифы, получателя платежа, способы оплаты, чек и техническую процедуру возврата в договоре провайдера. Сайт не заявляет, что ВТБ уже подключён. Банковский чек-лист пользователь пока не получил. Проверена доступность официального раздела банка https://www.vtb-bank.kz/smallbusiness/ekvayring/; конкретные условия интернет-эквайринга/одобрение данного бизнеса не подтверждены. Запрос к официальному тексту закона на Adilet в этой среде не вернул пригодный текст; актуальность и применение нормы ответа на претензию (10 календарных дней) нужно проверить при окончательном юридическом согласовании.
