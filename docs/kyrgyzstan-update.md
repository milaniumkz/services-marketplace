# Кыргызстан и доступность стран

Поручение владельца от 16.10.2026 заменяет Сербию на Кыргызстан. Текущие страны: Казахстан (KZ), Кыргызстан (KG), Россия (RU), Беларусь (BY). Это согласованное изменение к прежним макетам со страной RS.

Кыргызстан использует KGS (сом), +996, Asia/Bishkek, города Бишкек и Ош; язык по умолчанию — русский. Существующие переводы интерфейса и языки общения независимы от страны. Кыргызский перевод всего интерфейса не объявляется выполненным.

Изменены мобильный клиент, веб-клиент, публичный сайт, админка, API, контракты, OpenAPI и справочник категорий. Новые KG-категории создаются идемпотентно. Старые RS-аккаунты, документы, деньги и истории не переименовываются в KG и не переносятся в другую юрисдикцию.

Production-конфигурация включает все четыре страны через `JOBA_ENABLED_COUNTRIES`. `JOBA_REGION=KZ` описывает текущий хост; больше не блокирует остальные явно включённые страны. При отсутствии списка сохраняется прежний режим одного регионального хоста. Явная административная приостановка страны продолжает действовать. На проверенной опубликованной версии таких приостановок нет.

Release-сборка задаёт общий HTTPS API через `JOBA_API_URL`; каждый регион может получить отдельный URL при будущей необходимости. Сессии по-прежнему привязаны к стране и endpoint. Публичная доступность отражает действительные флаги регистрации и новых действий отдельно от готовности платежей. Отсутствующие платежи, реклама, push и региональные юридические документы не подменяются фиктивной готовностью.

Изменение в репозитории само по себе не обновляет работающий сервер. Статус публикации фиксируется отдельно в deployment.md.

Проверено 16.10.2026:

- Все workspace-сборки и release web Flutter прошли.
- Полная серия API: 85 passed, 0 failed; отдельный сценарий регистрирует и авторизует аккаунт каждой страны при одном хосте KZ и проверяет изоляцию справочника и учётных данных.
- Flutter: анализ 0 issues, 82 passed, 2 skipped (явные интеграционные/визуальные запуски).
- Полный административный/публичный браузерный сценарий прошёл; четыре статуса «Доступен» проверены по ответу API.
- `node scripts/verify-release-countries.cjs` проверяет опубликованию предназначенную Flutter web-сборку: каждая из четырёх стран выбирается и открывает вход без ошибки регионального endpoint. Это локальная проверка артефакта, а не проверка обновления сервера.

На момент проверки live API ещё возвращает прежнюю Сербию: изменение требует развёртывания нового commit. Фактическая production-версия в deployment.md остаётся прежней.
