# Общая админка и фильтр стран

Владелец платформы входит под прежней служебной учётной записью. Страна её регистрации не ограничивает общий обзор: по умолчанию выбран фильтр «Все страны». Аккаунты, заказы, проверки, услуги и портфолио, обращения, жалобы, аудит, задачи и финансовый журнал отображаются вместе. В списках показаны полные названия стран. Сводка и поиск работают в том же фильтре.

Фильтр «Страна» доступен сверху и в разделах рядом с другими фильтрами. Выбор сохраняется при переходах между разделами; смена фильтра сбрасывает курсоры страниц, но не завершает сессию. Карточка и действия владельца определяют страну по записи, поэтому белорусский аккаунт открывается и управляется из общей панели.

Региональные цены, документы и правила сохраняются по странам. При «Все страны» такие настройки показывают явно обозначенный домашний регион служебной учётной записи; выбор конкретной страны открывает её настройки. Финансовые события сохраняют свою валюту, суммы разных валют не складываются. Роли и сотрудники принадлежат служебному региону и не переносятся между странами этим фильтром.

Обычные сотрудники сохраняют ограничения своей роли и служебного региона. Параметр `admin_country` не даёт им доступа к чужому региону. Пользовательское приложение по-прежнему разделяет данные по странам. Режим `ALL` доступен только авторизованному владельцу для предусмотренных общих списков и отчётов.

Проверки включают четыре страны, глобальную пагинацию, региональный фильтр, открытие и блокировку белорусского аккаунта владельцем, общий поиск/сводку и отказ межрегионального доступа обычному сотруднику. Браузерная проверка использует изолированный реальный API и проверяет колонку страны, оба фильтра, карточку Беларуси и мобильную ширину. Производственные аккаунты для тестов не создаются и не изменяются.

## Фильтры заказов

Основные: страна, поиск по ID/названию/описанию, статус и город. В «Расширенных фильтрах»: ID заказа, заказчика и исполнителя, имена участников и часть адреса, название и ID категории, валюта, диапазоны бюджета и согласованной суммы, тип бюджета, формат работы, наличие исполнителя, фотографий и адреса, статус модерации, вид даты и диапазон дней включительно. Виды даты: создание, публикация, начало работы, завершение, отмена, истечение срока, обновление.

Суммы вводятся в единицах выбранной валюты с точностью до двух знаков. При общем обзоре поиск по сумме требует выбрать валюту. Даты фильтруются по UTC с включением всего конечного дня. Ошибки диапазона/валюты показываются в форме и направляют к нужному полю. Все критерии применяются в SQL до пагинации; удалённые заказы исключаются всегда. Выбранные критерии сохраняются в адресе раздела, «Сбросить» очищает их.
