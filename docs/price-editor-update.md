# Каталог цен с отдельными полями

Часть блока 5: маршруты `pricing` и `prices` используют структурированную форму вместо JSON. Доступ — сотрудники с billing и MFA, в своей стране.

Поля: название, подписка исполнителя / продвижение, сумма в валюте страны (KZT/KGS/RUB/BYN), календарный месяц/год для подписки; 7 суток, месяц, год или 1–366 суток для продвижения; провайдер, SKU и часовой пояс страны. Сумма сохраняется целым числом минимальных денежных единиц. Роль подписки задаётся сервером как executor; платного доступа заказчика эта форма не создаёт.

Собственный черновик можно изменить с `expected_version`; чужая или опубликованная версия сохраняется как новый черновик. Есть список и выбор версии по ID, проверка синхронизации, предпросмотр, независимая публикация, остановка и черновик отката. Несохранённые изменения блокируют команды. Сохранение не включает продажи.

Публикация требует реального ответа провайдера с совпадением **SKU, суммы и валюты**. Отсутствующий провайдер не заменяется успешной синхронизацией. Тестовые адаптеры используются только в изолированных тестах. Остановка версии не изменяет уже подтверждённые покупки или права. Из списка предложений подписки исключены продукты продвижения.

Остаются: визуальная приёмка A09/A22.prices, остальные формы блока 5, отдельные правила коммерческого изменения цен для существующих когорт и подключение реального провайдера. UI не выдаёт эти правила за реализованные. Изменения не развёрнуты на сервере.

Основной экран показывает действительную таблицу, фильтры состояния/продукта, поиск по названию, ID, SKU и провайдеру и действительное опубликованное промо. Форма открывается при создании или выборе версии. Таблица не объявляет ответы API демонстрационными данными. Проверка синхронизации сохранённой версии фиксируется в audit с причиной сотрудника.
