# Разовое продвижение и обращения в поддержку

## Продвижение в Казахстане

Тариф владельца: **100 ₸ за 1 сутки (24 часа)**, разовая покупка без автопродления.
В серверной цене `amount_minor: 10000`, в форме админки вводится **100**.

1. Войти в https://joba.com.kz/admin/ и выбрать страну «Казахстан».
2. Открыть **Каталог цен** (`#pricing`). Найти «Продвижение на 24 часа».
3. Для изменения опубликованной цены создать новую версию: продукт «Продвижение», провайдер `bcc`, SKU `joba.KZ.boost.24h`, цена 100, валюта KZT, период «Число суток», суток 1, часовой пояс Asia/Almaty.
4. Сохранить черновик, проверить синхронизацию и опубликовать. Владелец публикует настройки продвижения самостоятельно; для обычного сотрудника сохраняется независимое подтверждение.
5. В **Места и ёмкость** (`#placements`) управлять площадками и числом одновременных размещений. Для каждой отображаемой площадки первоначальная ёмкость — 1:
   - Поиск · услуги — `search.services.promoted`;
   - Поиск · заказы — `search.orders.promoted`;
   - Топ · услуги — `top.services.promoted`;
   - Топ · заказы — `top.orders.promoted`.
6. Состояние действующей цены и места должно быть «Опубликована». Обновить экран продвижения в приложении после изменения настроек.

Новые цены действуют на новые резервы; ранее созданные резервы сохраняют снимок цены.
Покупка доступна для опубликованной услуги либо открытого заказа, совместимого с выбранным местом. Занятые места не продаются повторно.
Настройка цены не меняет тестовую/рабочую среду банка и не подтверждает реальное списание.

## Поддержка

Открыть **Поддержка** (`#support`). По умолчанию видны все статусы; владелец может просматривать все страны или фильтровать страну верхним переключателем.

- Список обновляется каждые 5 секунд и при возвращении во вкладку.
- Сверху находятся обращения с последней активностью.
- Открыть обращение для чтения переписки. Для чтения не требуется предварительно назначать обращение себе.
- Для ответа сотрудник нажимает «Назначить себе», вводит текст и нажимает «Отправить ответ».
- Новые сообщения появляются автоматически; введённый черновик ответа сохраняется при обновлении.
- Доступ сотрудников ограничивается правами роли и страной; для вложений нужно отдельное право файлов поддержки.
