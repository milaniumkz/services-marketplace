# Структурированные политики документов

Часть блока 5 плана: `verificationPolicies` и `retention` используют отдельные поля вместо JSON.

Правила проверки: опубликованное основание страны, паспорт/удостоверение, от 1 до 4 обязательных страниц для каждого выбранного документа. Хранение: опубликованное основание и число суток после решения (1–365). Этот срок не заменяет политики чатов, заказов, финансов и аудита: блоки 8–10 остаются открыты.

Собственный черновик редактируется через PATCH с `expected_version`. Чужая или опубликованная запись при сохранении создаёт новый черновик. Детальная запись доступна по ID и вне первой страницы списка. Проверка, предпросмотр влияния, независимая публикация, остановка и черновик отката используют действительные API. Изменённые несохранённые поля блокируют команды. Предпросмотр не применяет политику.

Сохранение не является юридическим утверждением документа: основание должно быть опубликовано уполномоченными сотрудниками. Ни один срок не объявляется автоматически требованием законодательства.

Визуальная приёмка и остальные формы блока 5 остаются открыты. Изменения не развёрнуты на сервере.
