# Телефон и удаление аккаунтов

В карточке пользователя цель просмотра телефона заполнена заранее, видна сотруднику и доступна для изменения. Кнопка «Показать телефон» отображает полный номер; просмотр проверяет права и записывается в аудит. Пустое либо слишком короткое основание получает понятное сообщение на русском.

Удаление: выберите пользователя, выберите «Удалить аккаунт», укажите причину (от 3 символов), нажмите «Удалить аккаунт». Ввод ID и дополнительное окно подтверждения не требуются. Админка возвращается к списку пользователей. Аккаунт сразу получает статус «Удалён», все сессии отзываются, повторный вход и разблокировка недоступны. Самоудаление и удаление служебных аккаунтов через этот раздел запрещены. Права роли, версия записи, ключ повторного запроса и аудит сохраняются.

Очистка связанных записей выполняется существующим фоновым процессом. Удаление аккаунта не означает мгновенное физическое уничтожение всех заказов, платёжных записей и журналов. Сотрудника не переводит в раздел сроков хранения.

Проверки: браузер с изолированным реальным API проверяет показ номера, блокировку, разблокировку, удаление с одной причиной и аудит. API проверяет немедленный статус, отзыв доступа и невозможность повторного входа.
