# Быстрое управление пользователями

Карточка пользователя содержит кнопки «Показать телефон», «Заблокировать», «Разблокировать», «Удалить аккаунт». Причины, подтверждение ID и дополнительные формы не требуются. Удаление выполняется одним нажатием и возвращает к списку пользователей. Аккаунт сразу получает статус «Удалён», сессии отзываются, повторный вход и разблокировка недоступны.

Просмотр документов, селфи, фотографий, событий безопасности и полного IP также не требует ручного основания. В карточках проверок нет поля причины решения. Разрешения динамических ролей, границы страны, версия записи и защита повторных команд сохраняются. Самоудаление и удаление служебных аккаунтов через пользовательскую карточку запрещены. Журнал автоматически фиксирует сотрудника, тип действия, объект и время.

Очистка связанных записей выполняется в фоне. Удаление аккаунта не означает мгновенное физическое уничтожение всех заказов, платёжных записей и журналов. Сотрудника не переводит в раздел сроков хранения.

Проверки: браузер с изолированным реальным API проверяет отсутствие полей, показ номера, блокировку, разблокировку и удаление кнопками без диалогов; API — доступ без ручного основания, аудит, немедленный статус, отзыв сессий и невозможность повторного входа.

Удалённые аккаунты исключены из списка пользователей и общего поиска до пагинации, включая поиск по ID и фильтр удалённых записей. Прямая ссылка на удалённую карточку возвращает «Пользователь не найден». Заблокированные аккаунты остаются в списке и доступны для разблокировки.
