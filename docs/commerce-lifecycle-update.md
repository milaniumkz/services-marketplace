# Блок 8: восстановление, продление и рекламный доступ

19 октября 2026 устранена передача поздних результатов операций между аккаунтами. Общая проверка commerce-экрана фиксирует клиент, поколение сессии и владельца; восстановление, просмотр рекламы, управление подпиской и checkout проверяют её после каждого внешнего шага. Ошибка старой сессии не показывается новому аккаунту. Результат рекламы остаётся только outcome, право выдаёт сервер.

Восстановление с `pending` теперь открывает проверку соответствующей покупки, а не сразу «Мой доступ». Управление подпиской отображает срок/цену API в карточке по структуре S32.manage. Возврат от gateway не означает отмену: экран перечитывает серверный статус; отдельная проверка продления показывает отмену только при `canceled_at_period_end`. Без провайдера виден правдивый статус недоступности.

Проверки:

- Полный мобильный набор: 162 прошли, 2 пропущены (HTTP integration без JOBA_TEST_API_URL и отдельный визуальный инвентарь без параметров). После него добавлена проверка подтверждённой отмены и уточнено оформление; финальный целевой набор: 18 прошли.
- Анализатор мобильного приложения: 0 замечаний. Визуальный инвентарь отдельно: 115 состояний, 0 ошибок захвата. Все визуальные приёмки остаются открытыми.
- API: 13 прошли (`trust-and-providers`, `remaining-mobile-states`, `referral-reservations`). Подтверждены отсутствие права при pending/клиентском outcome, владение покупкой, порядок версий и replay, а также резервы/окно рефералов. Это изолированные провайдеры, не промышленная интеграция.
- Админские API: 5 прошли (`staff-roles`, `admin-review-permissions`, `staff-bootstrap`). `node scripts/verify-admin-browser.cjs` завершился успешно с реальным локальным HTTP API: MFA, динамические роли и ограниченная навигация, редакторы, независимое утверждение, приватные материалы, повторы потерянных ответов. Публикация и визуальная приёмка админки этим не подтверждаются.

Новые тесты находятся в `apps/mobile/test/remaining_states_test.dart`: смена аккаунта во время restore/reward/manage, pending-восстановление, фактическое подтверждение отмены. Тесты checkout и отказа неподключённого gateway сохранены.

Незакрыто: реальные адаптеры оплаты/рекламы, несколько покупок и сверка восстановлений у провайдера, все устройства/локали/страны и ручная визуальная приёмка.
