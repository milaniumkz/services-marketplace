# Запрос уведомлений в веб-приложении

После входа и разблокировки веб-приложение автоматически предлагает включить уведомления, если Firebase готов и браузер ещё не запрашивал разрешение. Предложение доступно поверх страниц приложения, нижнее меню сохраняется.

«Разрешить уведомления» сразу вызывает системный запрос браузера из обработчика нажатия. После согласия FCM-токен регистрируется в API для текущего аккаунта. Новый аккаунт или завершившаяся сессия не получают регистрацию от устаревшего действия. Если пользователь закрыл системный запрос без решения, повторный запрос через получение токена не вызывается.

«Позже» сохраняется в браузере на семь дней. Уже выданное разрешение используется автоматически; после запрета системный запрос повторно не навязывается. Разрешение можно изменить в настройках сайта браузера и повторно включить push через настройки уведомлений JOBA.

Во время регистрации повторные нажатия отключены. Ошибка регистрации не выдаётся за успех: предложение остаётся с возможностью повтора. При открытом приложении обновляются события и счётчики; в фоне уведомления показывает Firebase service worker. Ранее настроенная серверная очередь сохраняет категории, часы тишины и привязку к действующим сессиям.

Проверки: 23 теста предложения, настроек и входа; 7 тестов в Chrome, включая реальное сохранение предпочтения в localStorage и узкий экран с увеличенным текстом; анализ Dart без замечаний. Эти проверки не подтверждают получение push на физическом устройстве. APK не собирается.
