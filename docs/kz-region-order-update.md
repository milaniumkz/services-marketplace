# Порядок регионов Казахстана

В выборе области/региона Казахстана первыми отображаются **Астана, Алматы, Шымкент**, затем области по алфавиту. Записи без указанного региона находятся в конце списка. Данные остаются в серверной базе; в мобильном клиенте нет списка названий или особой проверки конкретных городов.

API `/geo/cities` отдаёт `region_sort_order` и `region_kind` из записей справочника. Компонент выбора сортирует группы по этому порядку и показывает подпись «Город республиканского значения» для соответствующего типа. Остальные страны сохраняют обычную сортировку без специального списка названий в клиенте.

Байконур не является отдельной группой первого уровня. Импортированная группировка Байконура и Торетама исправлена на Кызылординскую область. Сами города, их ID, координаты, алиасы и пользовательские ссылки не удаляются.

Перед проверкой маркера импорта выполняется идемпотентное исправление существующих GeoNames-записей. Это обновляет действующую базу даже при повторном запуске импорта; переименования, статусы и остальные редакторские изменения сохраняются. Повторный запуск без изменений не увеличивает версии. Изменение записывается в аудит.

Проверки: два серверных теста полного импорта и исправления старых записей, четыре теста компонента выбора, анализ Dart без замечаний. Веб обновляется при публикации; источник Android/iOS также исправлен, APK не собирается.
