# Политика паролей

По поручению владельца от 20.10.2026 минимальная длина нового пароля — 6 символов, максимальная — 128. Правило действует при регистрации во всех четырёх странах, смене пароля и создании служебного аккаунта. Подсказки и проверки регистрации в приложении обновлены; форма смены пароля получает региональные требования через `/me/security-policy`.

`DEFAULT_SETTINGS.password_min = 6`; администратор может задать более высокий минимум в настройках региона, нижняя граница валидатора — 6. Миграция `0012_password_minimum.up.sql` однократно устанавливает минимум 6 в существующих действующих настройках, увеличивая их версии. Таблица применённых изменений исключает повторную перезапись будущих настроек владельца при рестарте.

Проверки: 5 символов отклоняются, 6 принимаются; предел 128 сохраняется; ведущие/замыкающие пробелы не удаляются из пароля. Миграция сохраняет остальные поля настроек и применяется только один раз.

Для изменения клиентской проверки регистрации на Android нужен новый APK. Веб-клиент обновляется при развёртывании.

20.10.2026: сервер обновлён до `a0c5422` через Actions run `39425643063`. Реальный `/me/security-policy` проверен под владельцем во всех четырёх странах: минимум 6, максимум 128. Версия веб-файлов и HTTPS подтверждены; новый APK `testing/android-a0c5422` проверен по подписи, строкам нового правила и SHA-256 публичного скачивания.
