# Коммерческая информация на публичном сайте JOBA

По поручению владельца от 16.10.2026 подготовлены и подключены:

- W03 — полная политика конфиденциальности (существующий казахстанский источник, без изменения уже принятых версий).
- W06 — условия оплаты: предмет покупки, бесплатные функции заказчика, доступ исполнителя, отдельное продвижение, KZT, подтверждение платежа, электронное предоставление, автоплатёж только по отдельному согласию.
- W07 — возврат/отмена: основания, безопасные сведения для обращения, рассмотрение, возврат по исходной операции, полный/частичный возврат, отличие от отмены продления.
- W08 — публичная оферта на собственные услуги платформы; оплата работ специалиста не смешивается с оплатой JOBA.
- W09 — реквизиты/контакты и способы обращения. Поля реквизитов пустые по ранее данному поручению владельца, до приёма платежей их нужно заполнить.

Все публичные страницы содержат ссылки на новые разделы. Документы доступны без авторизации; содержимое генерируется в HTML из docs/legal/kz и читается без JavaScript. Сборка повторяема. Опубликованная версия API имеет приоритет над редакцией сайта; при ошибке проверки обновлений исходная редакция явно обозначается. Казахстанский русский текст не подставляется другой стране или языку. Документ можно скачать как TXT. Данные отображаются как текст, а не выполняемый HTML.

В админке «Правовые документы» добавлены типы payments/refunds/public_offer/contacts. Создание редакции и независимая публикация используют существующие версии, хеши и аудит. Начальный импорт при следующем развёртывании сохраняет любые существующие версии/черновики, в том числе прежний тип subscriptions. Сам платёжный провайдер этой работой не подключается.

Проверки: все workspace собраны; полный набор API на основной реализации — 94 успешно, 0 ошибок/пропусков. После дополнительной защиты прежнего типа payments/subscriptions прошли 3 целевых теста (публикация, сохранение админских правок и прежние документы). Браузерный набор прошёл: прямые страницы, отсутствие JavaScript, TXT download, приоритет опубликованной редакции, безопасный текст, смена страны без подмены документов, все пять страниц на ширине 390 без горизонтального переполнения. Визуальный набор — 72 кадра, без ошибок маршрутов; четыре новых страницы сохранены отдельно. Проверены повторяемость генерации и синтаксис скрипта развёртывания.

Перед отправкой банку остаются фактические реквизиты и контакты, окончательные тарифы/платёжный договор, чек и проверенная интеграция оплаты/возврата. Чек-лист ВТБ пользователь пока не получал. Одобрение банка и полное юридическое соответствие не заявляются; источники и границы правовой проверки — в legal/kz/README.md.

Изменения подготовлены в feature-ветке, на рабочий сервер этим блоком не развёрнуты. Приёмка 1:1 исходных макетов остаётся открытой; новые коммерческие страницы добавлены по отдельному поручению владельца, без искусственного увеличения числа принятых кадров.
