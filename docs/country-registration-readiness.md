# Регистрация и документы четырёх стран

Страны: KZ (Казахстан), RU (Россия), BY (Беларусь), KG (Кыргызстан). Все используют настроенный региональный API согласно конфигурации размещения.

`publish-country-readiness.cjs` выполняется из GitHub-развёртывания по прямому поручению владельца от 29 октября 2026 года. Он публикует только отсутствующие документы страны: пользовательское соглашение, политику конфиденциальности, условия оплаты и возврата, оферту, контакты и согласие на проверку личности. Источники находятся в `docs/legal/{country}`. Опубликованные административные редакции не заменяются.

Русские тексты доступны всем четырём странам. При отсутствии перевода API возвращает опубликованную русскую версию с её настоящими locale, ID и hash; неподтверждённый перевод не выдаётся за существующий. Регистрация принимает документы выбранной страны. Проверка личности требует две стороны документа и селфи для обеих ролей; подтверждение действует до ручного отзыва.

Однократный маркер фиксирует активацию регистрации. Последующие развёртывания сохраняют изменения владельца, включая временную остановку страны. В новых регионах включается обозначенная пользователю имитация оплаты без списаний, если режим ещё не настроен. Реальный подключённый платёжный адаптер имеет приоритет и отключает имитацию. Начальные тестовые цены задаются в валюте региона: заказчик 500, Стандарт 1000, Премиум 1500, отдельный Топ-100 500 за 30 дней; это не валютная конверсия. Цены редактируются серверным каталогом.

Реквизиты оператора оставлены для заполнения по ранее данному поручению владельца. Публикация текстов не подтверждает юридическую экспертизу, банковское согласование или физическую локализацию инфраструктуры в каждой стране. Эти сведения нельзя выдумывать по выбранной стране аккаунта.

Языки общения в «Моих услугах» выбираются несколькими отметками, без ручного ввода кодов. Источник названий — серверный каталог страны; редактор находится в админке «Категории и языки» → «Языки общения». Коды: ru, ky, kk, be, en.

Административное удаление заказа скрывает запись из рабочих списков, поиска и обычной карточки, закрывает связанные чаты и записывается в аудит. Служебная история сохраняется; статусы заказов показываются по общему русскому словарю.
