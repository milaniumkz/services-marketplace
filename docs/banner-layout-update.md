# Блоки 2–4: сверка A10 и A10.creative

Сравнение выполнено с исходными PNG и HTML, без изменения эталонов. Данные кампаний остаются серверными; демонстрационные названия, суммы и состояния не копируются в продукт.

## Исправлено

- A10.creative: высота полей и интервалы сетки, размер inline-предпросмотра, отдельная миниатюра/пустое состояние креатива, безопасное расположение текста, значок загрузки и группа кнопок выбора/загрузки.
- A10: добавлены отсутствовавшие блоки разрешённых размещений и исключённых экранов. Их текст отражает ограничения кампаний и недоступность внешних показов.
- Список показывает понятные названия размещений, статусные метки и даты периода. Полное местное время и IANA-зона остаются в подсказке периода. Фильтры, курсор и ссылки используют те же реальные записи API.
- Подписи таблиц кампаний и истории больше не объявляют реальные данные демонстрационными: показывают количество полученных записей, страну и наличие следующей страницы.
- Действие создания кампании получило оформление кнопки из макета; раздел в хлебных крошках — «Реклама».

## Проверки

Сборка админки успешна. Браузерный прогон через настоящий API прошёл после изменения разметки: загрузка/замена изображения, запоздавший ответ старого предпросмотра, потеря ответа сохранения и повтор без дубля, согласование другим сотрудником, отказ включения показов без провайдера, остановка и фильтры.

## Открытая приёмка

A10/A10.creative остаются pending. Общий shell, типографика, поля даты, фильтры и дополнительные служебные действия ещё отличаются от эталона. Макет содержит демонстрационный пример объявления; текущая страница списка объясняет разрешённые места без выдуманного действующего объявления. Это расхождение представления нужно закрыть при дальнейшей сверке. Отсутствие рекламного адаптера не позволяет проверять реальные показы. Рабочий сервер этой итерацией не обновляется.

Дополнительная браузерная проверка прошла: новые блоки, метка остановленной кампании, реальные подписи таблицы и отсутствие горизонтального переполнения на ширине 390 px. Сохранён `design/review/admin/banner-list-narrow.png`. Экспортированы 72 исходных состояния, ошибок маршрутов нет. После этого дополнительно уточнена подпись истории и русское название рекламы с вознаграждением; финальная сборка успешна.
