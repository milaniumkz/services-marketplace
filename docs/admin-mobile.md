# Мобильная админка

Адрес: https://joba.com.kz/admin/ . До 850 px боковое меню открывается отдельной панелью с затемнением фона; фон блокируется для ввода и прокрутки. Меню закрывается кнопкой, нажатием вне панели, Escape и переходом по ссылке. Фокус удерживается внутри открытого меню и возвращается к кнопке после закрытия.

Общий поиск доступен компактной кнопкой в шапке. На телефонах формы идут в одну колонку, основные элементы имеют высоту от 44 px, поля — шрифт 16 px. Таблицы сохраняют столбцы и прокручиваются внутри карточек, снабжены подсказкой и областью для клавиатурной прокрутки. Модальные окна ограничены размером экрана. Десктопная сетка восстанавливается при увеличении ширины.

`node scripts/verify-admin-mobile.cjs` проверяет готовую сборку с настоящим изолированным HTTP API и временной базой: 320/360/393/430/768 px × главная, аккаунты, категории, цены, настройки, страны, документы и роли. Проверяются отсутствие горизонтального выхода страницы, меню/фон/Escape, переход по меню, прокрутка таблицы и возврат к десктопу. Проверка включена в обязательный deploy workflow. `JOBA_ADMIN_MOBILE_SCREENSHOTS` задаёт каталог снимков при локальном запуске. Live HTTPS workflow дополнительно проверяет мобильную страницу входа на 320/393/430 px.

Изменение касается веб-админки и не требует пересборки Android-клиента.
