# Промо подписки и монетизация в админке — 15.10.2026

A09.promo получил отдельный редактор вместо универсального просмотра конфигурации. Название, начало по местному времени, дата окончания включительно, IANA-зона, аудитория, следующий опубликованный тариф и условия сохраняются в API. Страна берётся из служебной сессии, роль зафиксирована исполнителем, цена промо равна нулю, SKU вычисляется из выбранного тарифа. Цена продвижения не используется как следующий тариф подписки. На сервере отклоняется отсутствующее и неоднозначное время DST; начало должно предшествовать окончанию.

Собственный черновик редактируется через PATCH с expected_version. Чужая/опубликованная версия копируется в отдельный собственный черновик, а не перезаписывается. Просмотр версии по ID не зависит от первой страницы списка. Предпросмотр рассчитывает границу и показывает её в форме. После изменения полей кнопки проверки сохранённой версии отключаются до сохранения. Другая служебная учётная запись подтверждает публикацию; автор не может подтвердить её сам.

Новые аккаунты для аудитории промо — зарегистрированные не раньше его начала; существующие — зарегистрированные раньше. Действующая подходящая версия выдаёт исполнителю одно право до фиксированной границы, в том числе при открытии сведений о собственном доступе. На заказчика это правило не распространяется. Выдача использует уникальность источника/владельца в БД; повтор не продлевает срок. Автоматическая оплата следующего тарифа не создаётся.

A16 больше не описывает подписку как доступ для обеих ролей и не показывает цену boost вместо подписки. Набор возможностей рекламной награды сохраняется полностью. Кредиты действий исключают чтение поиска; действия бесплатного заказчика не предлагаются как платная награда. Баннерный флаг остаётся отдельной настройкой.

Внешние провайдеры не имитируются. Редактор banner creative по-прежнему не завершён: существующий banner-detail показывает конфигурацию, а не полный жизненный цикл креатива. Все кадры, включая обновлённые A09.promo, A09.preview и A16, остаются pending; наличие формы и браузерного снимка не подтверждает 1:1. Эта версия не опубликована на сервере автоматически.
