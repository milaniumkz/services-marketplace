# Редактор проекта портфолио — 15.10.2026

S38.edit получил отдельную форму вместо универсального списка полей и действий. Порядок соответствует макету: статус и сохранение, название, категория, фотографии с обложкой и добавлением, описание, связь с заказом, подтверждение прав. Отправка на проверку закреплена внизу. Названия, количество фото и статус берутся из API; демонстрационные тексты существуют только в изолированном визуальном тесте.

«Сохранить» сохраняет черновик. Отправка сначала сохраняет текущие поля и затем передаёт полученную версию в `/submit`. Переход к управлению фотографиями тоже сохраняет поля. Права подтверждаются checkbox, а связь выбирается из собственных завершённых заказов исполнителя. При ошибках поля и фото остаются на месте; успешное создание запоминается до прикрепления фото, поэтому повтор после отказа PATCH не создаёт второй проект. Конфликт версии требует явной загрузки актуальной записи. API продолжает проверять владельца, чистые файлы, категорию, выполненный заказ, права и доступ к публикации.

Проверено: 76 мобильных тестов passed, 2 дополнительных теста skipped; анализ 0 замечаний. Отдельная серверная проверка приватных черновиков и публикации портфолио passed. Получены 115/115 мобильных снимков без ошибок отрисовки. В снимке редактора исправлен отсутствовавший шрифт выпадающего списка; кнопка добавления получила пунктирную рамку и горизонтальное расположение.

Диагностическое расхождение пересчитано в visual-audit.json. S38.edit, как и остальные кадры, остаётся pending: данные, текст и растеризация влияют на метрику, и успешный тест не означает приёмку 1:1. Форма доступна в репозитории; публикация этой версии на сервере не выполнена. Остальные пункты ТЗ остаются в project-readiness.md.
