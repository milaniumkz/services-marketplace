# Промежуточная сверка native экранов

Снимки Flutter получены widget-прогоном на viewport 390×844, pixel ratio экспорта 2. Шрифты и SVG взяты из исходного макета. Изолированные данные проверяют компоновку и действия; рабочие экраны получают данные из API. Native SafeArea оставляет место для настоящей системной строки и панели жестов.

| Экран | Проверенные действия | Native снимок |
|---|---|---|
| S19 — предложить заказ | Выбор open-заказа, сообщение, отправка, повтор после ошибки без потери текста | [S19](mobile/S19-invite.png) |
| S20 — приглашения | Данные заказа/заказчика, срок, принятие → форма обычного отклика, отказ | [S20](mobile/S20-invitations.png) |
| S29 — жалоба | Причины, сохранение описания при смене причины, создание конкретного дела; API проверяет вложения и приватность | [S29](mobile/S29-report.png) |
| S30 — дела | Счётчики, открытые/решённые, курсор, карточка дела, новое обращение в поддержку | [S30](mobile/S30-cases.png) |

Оригиналы: `mobile/screens/S19-invite.png`, `S20-invitations.png`, `S29-report.png`, `S30-cases.png` внутри [исходного прототипа](../packages/JOBA_Mobile_Prototype.zip).

Воспроизведение из корня репозитория:

```bash
JOBA_SCREENSHOT_DIR=/tmp/joba-native-design-review bash scripts/flutter-mobile.sh test test/design_flow_test.dart --reporter expanded
```

Эти снимки фиксируют текущую реализацию, а не завершённую визуальную приёмку. Реестр [screen-audit.json](../screen-audit.json) сохраняет все 187 экранов/состояний и 2449 контролов. Поэкранное сравнение, остальные состояния и общая функциональная приёмка ещё не завершены. Значения pending нельзя менять на passed по одному наличию route или успешной сборке.
