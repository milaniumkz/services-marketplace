# Новые условия отклика, реклама, удаление и фотографии — 15.10.2026

Продолжение поэкранной сверки после формы отклика и списка предложений. Рабочие экраны получают данные из API; визуальный прогон использует отдельные изолированные записи.

| Экран | Реализация |
|---|---|
| S21.revision | Предупреждение, заголовок заказа, карточка версии/бюджета/сроков/описания и согласие по макету. Затем открывается редактор сохранённого отклика. Просмотр условий ничего не отправляет. Сохранение передаёт версии и подтверждённую ревизию. Для новых откликов сервер сохраняет снимок подтверждённых условий; старые записи без снимка показывают только доступные текущие данные. |
| S33 | Центрированный значок и заголовок, карточка награды/срока/суточного остатка, предупреждение, выбор подписки и нижняя кнопка. Остаток и пауза вычисляются сервером по собственным региональным сессиям, доступность провайдера проверяется по подключённым адаптерам. Без подключения просмотр недоступен. Завершение клиентского просмотра открывает ожидание серверного подтверждения и не выдаёт grant. Подтверждённая награда ведёт исполнителя к заказам. |
| S34.delete | Предупреждение и список активных заказов, экспорта и подписки. Подписка показывается только исполнителю при наличии соответствующей записи; у заказчика этой строки нет. Согласие необходимо для перехода к подтверждению. Подача запроса по-прежнему требует пароля, политика хранения и активные обязательства проверяются сервером. |
| S38.photos | Превью 220 px, отметка обложки, счётчик, кнопки обрезки/удаления, список порядка с меню обложки и перемещения. Все изменения сохраняются одной версионной командой; после ошибки выбранные порядок/обложка сохраняются. Обрезка создаёт настоящий производный файл через API. После «Готово» открывается редактор проекта. |

В версиях и сравнении бюджета стрелка рисуется SVG: отсутствие символа в шрифте больше не заменяет её квадратом. Исправлена совместимость старых откликов без явного срока: вычисленный срок ограничен завершением заказа, поэтому редактирование открытого заказа с более коротким сроком не отклоняется из-за несуществующего 72-часового продления.

Проверки покрывают отсутствие рекламного POST при отключённом провайдере, повторное получение условий, переход к ожиданию подтверждения без начисления, отсутствие подписки заказчика, явное согласие перед удалением, двухэтапное редактирование отклика, выбор/порядок/обрезку фотографий и повтор после отказа сохранения. Серверные проверки охватывают региональные рекламные остатки, снимок условий, подписку исполнителя и ограничение срока старого отклика.

Все кадры сохраняют pending. Наличие снимка и успешные тесты не подтверждают полного совпадения всех 187 кадров 1:1. Остальные расхождения и незавершённые пункты ТЗ перечислены в project-readiness.md; новые изменения репозитория не считаются опубликованными на сервере автоматически.

Итог проверки: сборка workspaces и 75 API-тестов — passed; полный мобильный прогон — 73 passed, 2 skipped; анализ — 0 замечаний. После SVG-правки повторно прошли 10 связанных widget-проверок. Повторно сняты 115/115 мобильных состояний, ошибок отрисовки нет. Визуальная приёмка по-прежнему открыта.
