# Оставшиеся 28 мобильных состояний — реализация и пределы проверки

Все 28 маршрутов имеют отдельную реализацию. Рабочие экраны используют API; данные в визуальном тесте изолированы. Снимки не означают визуальную приёмку 1:1.

| Маршруты | Реализованное поведение |
|---|---|
| `pin-setup`, `biometric`, `pin-limit` | Двойной ввод шестизначного PIN, проверка несовпадения, локальная защита, запасной вход с паролем, переход после исчерпания попыток. PIN не передаётся API. |
| `invited`, `cancel-pending` | Чтение собственного приглашения/запроса отмены и актуального статуса; переход к заказам. |
| `offer-revision` | Актуальные условия заказа; редактирование цены и комментария с явным подтверждением версии в одном PATCH. |
| `amendment`, `rework` | Версионированные команды изменения цены/даты и доработки; загрузка собственных фотографий. Предлагаемая дата меняется после согласия второй стороны. |
| `frozen-chat` | Проверка состояния переписки, запрет отправки на сервере, переход в поддержку. |
| `portfolio-photos` | Выбор обложки, перестановка, удаление фото из проекта, серверная квадратная обрезка в отдельный приватный файл. Интерактивное позиционирование рамки обрезки не реализовано. |
| `checkout`, `payment-pending`, `restore` | Настоящие опубликованные цены; подтверждение условий, проверка подписанного провайдером результата, чтение задания проверки, восстановление через подключаемый адаптер. |
| `manage-subscription`, `subscription-canceled` | Собственная подписка и оплаченный срок; управление через адаптер. Отмена не объявляется подтверждённой без состояния провайдера. |
| `reward-granted`, `reward-nofill`, `reward-pending` | Чтение рекламной сессии и настоящего grant; клиентский просмотр не выдаёт доступ. Учитываются истечение срока и исчерпание баланса. |
| `promotion-checkout`, `promotion-no-slots`, `promotion-terms` | Собственный резерв и срок, действительная цена, условия, обработка отсутствия мест и проверка оплаты. Отдельная выдача доступных продвигаемых карточек добавлена; возвраты требуют дальнейшей работы. |
| `consents` | Три необязательных согласия с версией и привязкой к опубликованному документу; отказ не закрывает приватность и поддержку. |
| `delete-account`, `delete-confirm`, `delete-scheduled` | Просмотр последствий, текущий пароль, собственный запрос, защита от дублей, окно отмены и ожидание завершения активной работы. Полный purge и управление законным удержанием ещё не закрыты. |
| `country-unavailable` | Реальные флаги доступности страны и разрешённые действия. |
| `gps-denied`, `map` | Ручной выбор города, нативный запрос приблизительной геолокации, поиск по радиусу, только опубликованные приблизительные зоны. Картографическая подложка ещё не подключена; демонстрационные улицы не используются. Мобильный редактор зоны добавлен в «Мои услуги»: новая зона сохраняется в черновик, отключение немедленно скрывает прежнюю точку. |

Новые проверки: несовпадающий PIN, отказ биометрии, единый запрос изменения отклика, согласие перед оплатой, ожидание платежа без выдачи доступа, отказ неподключённого адаптера, сохранение выбора согласий после ошибки. Backend дополнительно проверяет приватность состояний, отменяемое удаление, согласие с документом, дату изменения, замороженный чат, подтверждение платежа, отсутствие клиентской рекламной награды, карту и реальные байты обрезанной фотографии.

Внешние адаптеры оплаты, рекламы и push, инфраструктура, картографическая подложка, iOS-сборка и физические устройства остаются за пределами этой проверки. Также остаются визуальные расхождения: все кадры сохраняют `pending`. Полностью готовым проект пока не объявляется.
