# Управление оплатой и подпиской за рекламу

Владелец админки: **Подписка и реклама → Способы получения подписки**.

Доступны три независимых переключателя:

- **Оплата через БЦК** — разрешает новые платежи через БЦК.
- **Оплата через ВТБ** — разрешает новые платежи через ВТБ.
- **Подписка за рекламу** — разрешает начинать получение подписки за просмотры рекламы.

Изменение сохраняется сразу и действует во всех странах. Банковские реквизиты менять не нужно. Для временного доступа только за рекламу выключите оба банка и оставьте подписку за рекламу включённой. Для возврата оплаты включите нужный банк.

Обычные рекламные баннеры работают независимо от этих переключателей. Действующие подписки, накопленные просмотры и проверка уже начатых платежей сохраняются. Количество необходимых просмотров настраивается в настройках подписки за рекламу ниже.

По умолчанию все три переключателя включены. Проверки переключения выполняются только в изолированном окружении.
