# S31: непустой список событий, категории и переходы

19 октября 2026 восстановлена структура исходного S31: белая шапка «События», кнопка настроек, вкладки «Все / Заказы / Аккаунт», группы «Сегодня / Вчера / дата», общие карточки с разделителями, иконками, временем для рабочих сообщений и отметкой «Новое». События берутся из API; имена, заказы и даты макета используются только в изолированной визуальной фикстуре. В ней выбрана роль исполнителя для исторического события о подписке.

Категории фильтруются на сервере до пагинации. Рабочие события и ссылки на заказ/отклик относятся к «Заказы», события профиля, проверки, подписки, портфолио и приватности — к «Аккаунт»; поддержка и прочие события остаются в «Все». История сортируется по created_at от новых к старым, при равенстве — по ID. Подписанный курсор привязан к владельцу, стране, категории и порядку; удалённая опорная запись требует обновления. SQL выбирает уведомления текущего аккаунта, вместо загрузки уведомлений всей страны.

«Прочитать все» перенесено ниже истории. Счётчик приходит из API и уменьшается после подтверждённого чтения своего элемента; поздний ответ старого списка не меняет счётчик новой выборки. При пагинации сохраняется граница первой страницы, при pull-to-refresh/перезапуске курсора она очищается и загружается заново. После выхода категория возвращается в «Все». На узком экране вкладки допускают горизонтальную прокрутку, текст строк переносится.

Переходы исходных строк: отклик → список откликов данного заказа, готовность работы → результат для приёмки, поддержка → обращение, проверка → фактическое состояние проверки, подписка → «Мой доступ», портфолио → свой проект. У заказчика переход из события подписки показывает бесплатные возможности. Кампании с deep_link продолжают использовать отдельную проверку ссылки/доступа; это не заменяет авторизацию целевого API.
