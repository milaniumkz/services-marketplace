# Границы каркаса

Демо не обрабатывает аккаунты, личные данные, геолокацию или платежи. API и админка по умолчанию слушают localhost. Health — liveness процесса, не проверка БД. Перед реальными данными нужны согласованные авторизация/RBAC, validation, rate limits, безопасный storage, управление секретами, аудит без PII, сроки удаления, backup/restore и проверка требований стран. Документы личности не хранятся бессрочно. Репозиторий private не является production-защитой.
