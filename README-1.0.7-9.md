# JOBA 1.0.7 (9), тестовый APK

Сборка из проверенного кода 50ef35b, сервер https://joba.com.kz.

- Единое окно фронтальной камеры лица, автоматическая фиксация пяти этапов и озвучка.
- Переключатель биометрии с сохранением PIN и сессии.
- Документы по странам, исправления входа и поиска рядом.
- Подписки, реклама и банковская форма внутри приложения включены.

Подпись тестовая, совпадает с предыдущими тестовыми APK. Поверх версии Google Play с другой подписью Android установить этот файл не позволит. Магазинная публикация не выполнялась. На физическом телефоне в этой среде запуск не выполнялся. Банковский контур БЦК пока тестовый: реальные платежи не заявлены.
