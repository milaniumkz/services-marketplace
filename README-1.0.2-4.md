# JOBA 1.0.2 (4) — APK для тестирования

Android 7.0 и новее; универсальный APK. Оптимизированная release-сборка с тем же тестовым сертификатом, что у тестового APK 1.0.1 (3). Можно обновить предыдущий тестовый APK без удаления данных. Версию Play с другой подписью не заменяет; не удаляйте её без необходимости, удаление стирает локальный PIN и черновики.

Настоящий API: https://joba.com.kz. Подписки, реклама за вознаграждение, приглашения и автоматическая биометрия сохранены.

Изменения: общий с вебом поиск ближайших заказов, точные координаты, параллельное определение GPS/сеть, сохранение экрана после запроса разрешения, один нативный баннер на сессию, обработка ошибок освобождения SDK, OpenGL для совместимости Android, диагностика предыдущего завершения процесса.

Проверено: 305 тестов Flutter (2 пропуска), 2 браузерных теста геолокации, анализатор без замечаний, подпись APK, выравнивание 16 KiB, версия и архитектуры. Физический телефон в этой среде недоступен; исходное закрытие процесса на телефоне не воспроизведено. Поэтому отсутствие любых будущих падений не гарантируется.

Проверка на устройстве: обновить прежний тестовый APK → разрешить геолокацию → исполнитель: ближайшие заказы → заказчик: создать, сохранить предпросмотр, опубликовать и выбрать исполнителя → переключать разделы и оставаться в приложении 10–15 минут → проверить подписку/рекламное вознаграждение. Реальные действия выполняются на рабочем сервере. После неожиданного закрытия запустите приложение снова: на Android 11+ причина прошлого завершения попадёт в диагностику Firebase.
