## Проверка анкет

Приложение использует аккаунты, телефон, профиль, пользовательские сообщения, фотографии/вложения, приблизительное местоположение, идентификаторы аккаунта/устройства и push. Проверка личности обрабатывает удостоверение и селфи; функция восстановления по лицу требует отдельного учёта биометрических данных. Нельзя декларировать «данные не собираются». Для Apple проверить также Other Sensitive Data / Other User Content; для Google — Personal info / Other info, Photos and videos, Messages, Location, Device or other IDs. Цели и связь с аккаунтом указывать по реальной реализации и настройке сервера; сбор для рекламного tracking не следует выводить только из наличия Firebase Messaging.

Сервис предназначен для совершеннолетних. Пользовательский контент и общение присутствуют: ответы о наличии UGC, жалоб, блокировок и модерации должны учитывать это. Возрастной рейтинг определяется ответами анкеты магазина, а не произвольным выбором рейтинга 18+.

## Выявленные ограничения

- Добавлена Android release signing configuration через переменные окружения. `python3 scripts/build-store-android.py` читает закрытую конфигурацию `~/.joba-publication/android-signing.json`; ключ и пароли находятся вне репозитория. Ключ необходимо сохранить для будущих обновлений. Тестовый APK не подходит для Google Play.
- Зарегистрирован Apple App ID `kz.joba.servicesMarketplace`; архив и IPA успешно подписаны командой `Z3NZN92Y7P`, IPA загружен в App Store Connect.
- Нативные Apple/Google Billing отсутствуют. Платные цифровые функции JOBA (доступ к платформе, продвижение) требуют отдельной проверки правил покупок магазинов. Оплата физических работ специалиста — другой предмет платежа.
- Серверные `payments`/`public_offer` v4 от 27.10.2026 вводят подписку заказчика, а `contacts`/`refunds` v2 сохраняют старое утверждение о бесплатном доступе. Описание карточек не обещает бесплатный доступ.
- Политика конфиденциальности содержит первоначальные оговорки о неподтверждённой локализации, неопределённых сроках хранения и ещё не подключённых интеграциях. Анкеты должны отражать текущее фактическое состояние, а политика — соответствовать ему.
