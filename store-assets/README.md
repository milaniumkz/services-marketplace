# JOBA — пакет публикации

02.11.2026 отправлена бесплатная мобильная версия 1.0.0 (2):

- App Store: **Ожидание проверки**, автоматический выпуск после одобрения. App ID 6829684954, bundle `kz.joba.servicesMarketplace`.
- Google Play: **Изменения на проверке**, рабочий выпуск сборки 2, управляемая публикация выключена. Package `kz.joba.services_marketplace`.
- Страны выпуска: Казахстан, Кыргызстан, Россия, Беларусь.

Исходники получены из `feat/joba-implementation` (ad0713814f40e99f39556a10fe07eebd73acee86). Изменения публикации — ветка `Project/store-publication`, код сборки и сервера 3b540f0. Серверное развёртывание успешно: https://github.com/milaniumkz/services-marketplace/actions/runs/41427061622 . Вход демонстрационного аккаунта проверен. Веб-файлы не заменялись.

Мобильная версия не предлагает подписки, встроенные покупки, платное продвижение или бонусные вознаграждения. Основные операции бесплатны; проверка личности, права владельца, модерация и ограничения аккаунтов сохраняются. Реализация: `docs/mobile-free-release.md`. Оплата реальной работы специалиста согласуется сторонами отдельно. Веб-продукт сохраняет отдельную ценовую политику.

`metadata/ru-RU.json` содержит описания, ключевые слова и публичные контакты, сверенные с серверными документами. `raw/` и `raw-ipad/` — снимки реальных Flutter-виджетов с вымышленными тестовыми данными. `screenshots/` — оформленные изображения, загруженные в магазины: пять Android 1080×1920, пять iPhone 1206×2622, пять iPad 2064×2752. `graphics/` — значки и баннер. `preview.jpg` — обзор оформления.

Заполнены Apple App Privacy (14 типов, связь с аккаунтом, без рекламного tracking), анкеты Google, доступ проверяющим и возрастные сведения. Целевая аудитория — 18+; IARC присвоил региональные рейтинги по ответам анкеты. Пользователь отдельно подтвердил Google export declaration, Apple privacy publication и условия IARC. Проверочный аккаунт обозначен демонстрационным, имеет роли заказчика и исполнителя без прав персонала; паспорт проверяющим не нужен.

Подписанные файлы вне Git: `release/store/JOBA-1.0.0-2.aab` и `release/store/JOBA-1.0.0-2.ipa`. Контрольные суммы и проверки — `build-verification.json`. Flutter analyze прошёл; API build и тесты бесплатного доступа прошли. Исходный полный Flutter-прогон: 292 passed, 2 skipped, 2 failed; оба упавших файла исправлены и повторно прошли. Финальные phone/iPad captures прошли. Flutter 3.44.1, Xcode 26.0.1, Android target API 36.

Ключ Android для будущих обновлений хранится в `~/.joba-publication/android-upload.jks`, закрытая конфигурация — рядом. Пароли, приватные ключи и данные проверочного аккаунта не публикуются в Git. Скриншоты консолей находятся в игнорируемом `evidence/`.

Отправка на модерацию не означает одобрение или появление приложения в магазинах. Итоговое решение принимают Apple и Google.

Пересоздать оформление: `python3 scripts/prepare-store-assets.py`. Снимки Flutter создаются тестом `test/design_flow_test.dart` с `JOBA_STORE_CAPTURE_ONLY=1` и `--dart-define=JOBA_FREE_MOBILE=true`; планшетный размер задаётся `JOBA_CAPTURE_WIDTH=1032 JOBA_CAPTURE_HEIGHT=1376`.
