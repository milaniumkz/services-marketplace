# JOBA 1.0.4 (6): тестовая оплата ВТБ

Тестовый APK подключён к https://joba.com.kz. Подписан тем же тестовым ключом, что версии 1.0.1–1.0.3. Для магазина нужен прежний магазинный ключ подписи.

1. Установите APK и войдите в свой аккаунт.
2. Откройте «Мой доступ», выберите тариф и подтвердите условия. Нажмите «Продолжить оплату».
3. Откроется тестовая страница ВТБ. Используйте только публичную тестовую карту банка: **2201382000000062**, срок **12/34**, CVC **123**. Настоящие карты для тестового контура не используйте.
4. После оплаты вернитесь в JOBA. Результат проверится автоматически; можно нажать «Проверить оплату».
5. Если окно банка закрылось, незавершённая оплата находится в «Мой доступ». Повторно оплачивать не нужно.

Доступны подписка заказчика, Стандарт, Премиум, доплата за немедленное повышение, немедленное понижение с переносом оплаченного остатка, продление, отдельный Топ-100 и продвижение. Реферальные скидки и доступ за рекламу сохраняются.

Цены: админка → «Подписка и реклама» → цены подписок. Для ВТБ отдельные банковские SKU подписок создавать не нужно. Возвраты оформляются через заявки в JOBA и подтверждаются банком.

Для настоящих платежей ВТБ должен выдать боевые API-реквизиты. Пока включён sandbox: реальные деньги не списываются.

Подробная инструкция: https://github.com/milaniumkz/services-marketplace/blob/feat/joba-implementation/docs/payments/VTB.md

Проверены 211 серверных сценариев, 311 Flutter-тестов, 21 браузерный сценарий, 11 окончательных финансовых проверок. На настоящем шлюзе sandbox выполнены оплата, выдача подписки, возврат и отзыв доступа. APK проверен по подписи и выравниванию 16 KiB. Проверка на физическом телефоне остаётся тестированием пользователя.
