# JOBA 1.0.5 (7): оплата внутри приложения

Форма ВТБ открывается во встроенном окне JOBA, без перехода во внешний браузер. После возврата банка окно закрывается; результат подтверждает сервер. Ручное закрытие окна сохраняет незавершённый платёж в «Мой доступ».

В тестовом окне нажмите значок «Тестовая карта»: доступны реквизиты и копирование номера.

- Тестовая карта банка: 2201 3820 0000 0062.
- Срок: 12/34.
- CVC: 123.

Настоящую Visa в sandbox использовать не нужно. Для настоящих платежей банк должен предоставить боевые реквизиты и подтвердить приём карт Visa боевым мерчантом.

APK подписан тем же тестовым ключом, что версии 1.0.3 и 1.0.4. Для магазина используется прежний магазинный ключ.

Проверены анализатор, 10 целевых тестов открытия/закрытия, HTTPS-переходов 3DS, серверной проверки оплаты и сохранения состояния, а также веб-сборка. На тестовом шлюзе проверены банковская форма с мобильным WebView-идентификатором, оплата и возврат. Запуск на физическом телефоне не выполнялся. Подпись и выравнивание APK 16 KiB проверены.
