# JOBA 1.0.10 (12), тестовый APK

Сборка из кода 5b21098, сервер https://joba.com.kz.

- БЦК открывается внутри JOBA во встроенном WebView, без внешнего браузера.
- Возврат банка через POST закрывает банковское окно и запускает серверную проверку оплаты.
- На экранах входа и регистрации доступны политика, соглашение и остальные документы в модальном окне. Введённые данные сохраняются.

Подпись тестовая, совпадает с предыдущими тестовыми APK. Поверх версии Google Play с другой подписью Android установить этот файл не позволит. На физическом телефоне в этой среде запуск не выполнялся. Контур банка тестовый, промышленная оплата не заявлена.
