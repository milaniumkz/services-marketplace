# JOBA 1.0.6 (8)

Установите поверх предыдущего тестового APK: подпись совпадает с версиями 1.0.3–1.0.5.

Исправлено:

- Кнопка «Продолжить без настройки лица» закреплена под прокручиваемым содержимым и доступна на небольшом экране с крупным шрифтом.
- Для обеих сторон удостоверения снова можно выбрать галерею либо камеру.
- Селфи и кадры восстановления по лицу снимаются встроенной фронтальной камерой. Задняя камера вместо фронтальной не выбирается. Звук не записывается, разрешение на микрофон отсутствует.
- Заказчик с активной подпиской может приглашать исполнителя без повторной оплаты за отсутствие подписки у получателя. Это исправление уже опубликовано на сервере. Собственный доступ исполнителя проверяется при принятии приглашения.

Оплата внутри приложения сохранена. Пока используется тестовый контур ВТБ: карта 2201 3820 0000 0062, срок 12/34, CVC 123. Настоящие карты пока не используйте.

Проверены 30 целевых Flutter-тестов, 11 серверных сценариев приглашений и оплаты, анализатор, подпись, выравнивание APK и 64-битных ELF-библиотек 16 KiB. Физический телефон в этой среде не использовался: проверьте обновление на своём устройстве перед магазинной публикацией. Для магазина нужен прежний магазинный ключ подписи.
