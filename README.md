# Services marketplace

Техническая основа отдельной биржи услуг для RS/KZ/RU/BY. Заказчики ищут исполнителей, исполнители — разовые или проектные заказы по своим услугам. Бренд ещё выбирается; постоянные вакансии не входят в продукт.

[Полное ТЗ v1.0 на русском](docs/spec/services-marketplace-spec-v1.ru.md) · [STATUS: implemented / partial / not_started](docs/STATUS.md) · [проверки](docs/verification.md).

ТЗ описывает целевой продукт, а этот репозиторий содержит проверенный scaffold. Наличие health, demo-экранов и типов не означает готовый backend или выполненный первый релиз. Markdown сохранён без изменения текста; PDF/DOCX переданы пользователю отдельно и сейчас не импортируются в репозиторий.

| Казахстан | KZ | ru, kk | KZT |
| Россия | RU | ru | RUB |
| Беларусь | BY | ru, be | BYN |

Целевой P1 включает Flutter iOS/Android, backend, административную панель и адаптивный публичный сайт. Услуги, профили/аватары, двусторонний поиск, заказ/приглашение/отклик, чат, завершение/споры, взаимные отзывы, жалобы/блокировки/апелляции ещё не реализованы. Полный web-кабинет — предложенный P2, см. D15.

По ТЗ регистрация/вход — телефон + пароль без SMS вообще; номер unverified, не доказательство владения и не фактор reset. Google/Apple не обязательны. Region-first, Argon2id, сохранённая серверная сессия и локальный PIN/поддерживаемая биометрия пока не реализованы. Локальная разблокировка не заменяет серверную проверку и не восстанавливает отозванный доступ. Recovery — открытый D17; обязательная почта не согласована. Проверка личности отдельная; GPS только с согласием, точностью и временем; IP — приблизительное место.

Подписка — постоянная продуктовая опция; баннеры и rewarded-доступ переключаются независимо после реализации защищённой админ-конфигурации. Inline-баннер не перекрывает управление и не выдаёт entitlement. Бесплатный промодоступ до даты, затем платный тариф не означает списание без согласия или произвольный store SKU за 0. Оплата услуг и комиссия с заказа исключены. Платёжные/рекламные провайдеры и core pay-or-reward policy требуют проверки по каждой стране; в demo все платежи unverified, checkout выключен.

Словари по стране/языку должны создавать карантин, временный hold и дело с человеческим решением, версиями/контекстом/аудитом; новые правила не выполняют массовый ретроактивный бан по умолчанию. Поддержка и апелляции доступны, цитата оспариваемого слова не вызывает повторный hold. Push-кампании требуют сегментов, consent, расписания/отмены и безопасных links с auth/region/object/entitlement checks. Launcher-иконка: admin asset preparation → новая сборка → отдельно разрешённый релиз; upload не меняет тихо иконку на устройствах. Рефералы — одноуровневые настраиваемые привилегии, без денежных выплат и произвольного изменения магазинных списаний. Всё это пока not_started.

## Текущий состав

- `services/api` — NestJS/TypeScript, только `GET /health` (liveness), без БД и бизнес-API.
- `apps/admin` — TypeScript/Vite, статичная demo-страница. Целевой Next.js из ТЗ ещё не внедрён.
- `apps/mobile` — Flutter demo и native iOS/Android templates; analyze/widget test прошли, native builds не запускались.
- `packages/contracts` — health/страны и частичные demo-модели auth/монетизации; это не полный OpenAPI или production security.
- `infra` — незапущенный шаблон PostgreSQL/PostGIS; нет Redis/S3 emulator, полного local stack или deployment.
- `docs/spec` — полный неизменённый Markdown ТЗ v1; `docs` — статус, инструкции и пояснения границ.

[Локальный запуск и тесты](docs/local-development.md) · [границы безопасности](docs/security.md).

Репозиторий публичный. Секреты и персональные данные запрещены; `.env.example` — placeholders. Реальные платежи, реклама, регистрация и сбор персональных данных не включены. CI/Actions, self-hosted runners, Docker/Colima и production deployment не запускались. Дальнейшая разработка — отдельными feature branches/draft PR с согласованием открытых решений раздела 41; текущий PR не merged.
