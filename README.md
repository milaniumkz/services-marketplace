# JOBA — тестовый APK

Android 7.0+, ARM64, debug. Источник приложения: `37699b8`. API: https://joba.com.kz .

Выбор города: область/регион → город, поиск по всей серверной базе. Категории: основные разделы → подкатегории → специализации, глобальный поиск с путём категории.

Страны: Казахстан, Кыргызстан, Россия, Беларусь. Стандарт: 1000 на 30 дней; Премиум: 1500 на 30 дней и приоритет услуг в Топ-100. Цены задаются в местной валюте страны и меняются владельцем в админке. Реальные платежи требуют подключения провайдера.

Скачайте APK, разрешите установку из выбранного браузера, подтвердите установку/обновление. Для магазина эта debug-сборка не предназначена. Не используйте её для измерения итоговой скорости release-сборки. Доступ к аккаунтам работает через реальный сервер, демонстрационные покупки не имитируются.

Контрольная сумма и точные сведения: `build.json`, `.apk.sha256`.
