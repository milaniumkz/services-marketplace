# JOBA — тестовая APK и инструкция

[Скачать APK для Android 7.0+ ARM64](JOBA-testing-arm64-debug.apk?raw=true) · [Инструкция заказчику: Google и Яндекс, PDF](JOBA-advertising-owner-guide.ru.pdf?raw=true)

1. Скачайте APK на 64-битный Android-телефон. Для старых 32-битных устройств этот файл не подходит.
2. Откройте файл. Если Android попросит, разрешите установку именно из используемого браузера/файлового менеджера, затем установите JOBA.
3. Используйте свой аккаунт или зарегистрируйте тестовый. База сервера не очищалась. Если установщик сообщает о несовместимой подписи, сначала убедитесь, что помните вход; удаление старой тестовой APK удалит локальный PIN/сессию, но не серверный аккаунт.

Это **debug-сборка для функционального тестирования**, подписана Android test-ключом; не предназначена для магазина или оценки итоговой производительности. Остальные ABI удалены из уже собранного APK; архив выровнен и заново подписан тем же test-ключом. Подпись, package, Android API, ABI, разрешение INTERNET и скомпилированный HTTPS URL проверены. На физическом устройстве запуск не проверялся. Данные сборки и SHA-256 находятся рядом.

Источник приложения: `375e587de5a46c99e91e42dd983261fa06235779`. API: https://188-241-217-228.sslip.io/ . Рекламные SDK, реальные платежи и Firebase ещё не подключены.

**Сервер пока не обновлён.** Последняя успешная версия — `75cedf3`; в публичном конфиге ещё RS вместо KG. Обновление `375e587` прошло сборку/проверки, но не получило SSH credential. Владелец должен добавить `JOBA_SSH_PASSWORD` или `JOBA_SSH_PRIVATE_KEY` в Settings → Secrets and variables → Actions: https://github.com/milaniumkz/services-marketplace/settings/secrets/actions . Интеграция возвращает HTTP 403 при управлении Secrets и не может добавить их самостоятельно. До успешного обновления новые API-сценарии и Кыргызстан могут быть недоступны.
