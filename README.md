# JOBA — services marketplace

Маркетплейс услуг JOBA. Заказчики ищут исполнителей, исполнители ищут заказы по своим услугам; постоянные вакансии не входят в продукт.

Ветка содержит развиваемый backend JOBA по опубликованному ТЗ v1.1. Полный релиз и соответствие каждого экрана макету ещё не подтверждены: [статус backend](docs/backend-status.md), [запуск](docs/backend-development.md), [ТЗ](docs/specification-status.md).

| Страна | Код | Языки | Валюта |
|---|---|---|---|
| Сербия | RS | sr | RSD |
| Казахстан | KZ | ru, kk | KZT |
| Россия | RU | ru | RUB |
| Беларусь | BY | ru, be | BYN |

Планируемый объём: услуги, заказы и отклики, чат, профили/аватары, репутация заказчика и исполнителя, жалобы, блокировка и апелляции. Серверные сценарии реализуются в этой ветке; подробная граница готовности приведена в отчете backend.

Вход пользователя — номер и пароль без SMS и email. Staff использует отдельный вход с MFA. PIN/системная биометрия — локальная защита сохранённой сессии, не проверка документа исполнителя. GPS используется только с согласием, с точностью и временем измерения; IP не определяет точное место.

Подписки и рекламный доступ конфигурируются админом. Реальная монетизация требует проверки провайдеров по каждой стране; для России учитываются ограничения Play Billing, AdMob и Apple. Доступ к удалению аккаунта, приватности, поддержке и восстановлению оплаты нельзя закрывать оплатой. Документы личности не хранятся бессрочно.

## Состав

- `services/api` — NestJS/TypeScript, PostgreSQL/PGlite, бизнес-маршруты `/api/v1`, права, сессии и доменные сценарии.
- `apps/admin` — Vite, оригинальные макеты и частичная интеграция staff API.
- `apps/client` — мобильный web-клиент с оригинальными макетами и частью живых API-сценариев; не заменяет native приложения.
- `apps/web` — публичные страницы по макетам, безопасный pre-login support API.
- `apps/mobile` — Flutter-клиент с Android/iOS runners и подключением API; [запуск и границы готовности](docs/mobile-development.md).
- `packages/contracts` — минимальные типы health и кодов стран.
- `infra` — не запущенный шаблон PostgreSQL/PostGIS.
- `docs` — инструкции и границы реализации.

[Запуск и проверки](docs/local-development.md) · [Безопасность](docs/security.md).

Секреты и персональные данные не добавлять. `.env.example` содержит только placeholders. Платные Actions, self-hosted runners, production deployment, реальные платежи, реклама и сбор персональных данных не настроены. После утверждения ТЗ разработка идёт в отдельной feature branch через draft PR.
