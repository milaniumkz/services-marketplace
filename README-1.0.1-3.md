# JOBA 1.0.1 (3) — тестовый APK

Android 7.0 и новее. Универсальный APK, оптимизированная release-сборка с тестовой подписью. Сервер настоящий: https://joba.com.kz.

Автоматическая биометрия включена в общий код: при включённой биометрии на экране PIN появляется системный запрос, отмена оставляет PIN. Подписки, реклама, приглашения и остальные изменения включены.

Тестовая подпись отличается от Play: поверх установленной версии из магазина такой APK не обновится. Используйте отдельное тестовое устройство; удаление прежнего приложения стирает локальный PIN и локальные черновики. Для Play соберите AAB с прежним ключом по инструкции в репозитории. На физическом телефоне эта сборка здесь не запускалась.
