# Миграции

SQL up-миграции нумеруются последовательно, уже применённые файлы не меняются. Сейчас подготовлен только PostGIS, бизнес-таблиц нет. Runner и журнал применений выбираются после ТЗ. Не выполнять файл автоматически при старте API. Применение вручную только к выделенной локальной БД: `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f services/api/migrations/0001_extensions.up.sql`. Автоматического rollback нет: удаление extension может повредить зависимые данные.
