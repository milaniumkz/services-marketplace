# JOBA mobile demo

Flutter iOS/Android scaffold, without accounts, GPS, payments or user data.

Run `flutter pub get`, `flutter analyze`, `flutter test`, then `flutter run` using an existing SDK. Verified with Flutter 3.41.1 / Dart 3.11.0. Native runners included; native builds not yet verified. Configure your own signing team locally and replace the temporary `com.example.services_marketplace` identifier before release.
