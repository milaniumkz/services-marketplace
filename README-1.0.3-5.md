# JOBA 1.0.3 (5) — тестовый APK с серверным журналом сбоев

Оптимизированная release-сборка, Android 7.0+, универсальный APK. Подпись совпадает с прежними тестовыми APK 1.0.1 (3) и 1.0.2 (4): устанавливайте поверх, не удаляя приложение. Поверх версии Play с другим сертификатом этот файл не устанавливается.

Серверный журнал уже опубликован и проверен на https://joba.com.kz. После установки этой версии ошибки Flutter/Dart отправляются автоматически, данные необработанного Java/Kotlin-сбоя и доступные сведения Android о закрытии процесса — при повторном запуске. Без сети отчёты сохраняются в приватной очереди. Ничего вручную копировать не нужно. Пароли/токены/контакты редактируются, формы/фото/переписка не читаются.

Последний экран, переходы, модель/Android, версия и стек помогут диагностировать следующий сбой. Сервер хранит журнал 30 дней. Сбой при физическом отключении/полном диске и некоторые сигналы Android могут не оставить полного стека; сведения о системном завершении зависят от Android.

Для разработчика: python3 scripts/fetch-mobile-crashes.py --output /tmp/joba-mobile-crashes.json. Выгрузка по SSH через защищённый workflow зашифрована, открытые стеки не публикуются в Actions. R8 mapping для этого APK находится в JOBA-1.0.3-5-symbols.zip. Полная инструкция в docs/hand-off/JOBA-mobile-server-crash-logs-2026-11-04.md.

Сохранены предыдущие исправления геолокации/баннеров, подписки и автоматическая биометрия. Работа идёт с настоящим сервером. На физическом телефоне здесь APK не запускался.
